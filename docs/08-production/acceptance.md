# 완료 기준과 검증

- 상태: 초안 — 구체 시나리오 미정
- 담당: 기획자 + AI
- 관련 문서: [MVP](../01-vision/scope.md), [명세 양식](../templates/system-spec.md)

기능마다 다음을 작성한다.

- 선행 상태와 데이터.
- 플레이어 행동.
- 기대 상태 변화와 화면·소리 피드백.
- 실패·취소·앱 중단·재시작 결과.
- 검증 환경, 방법, 실제 결과.

결과는 `통과 / 실패 / 미실행`으로 구분한다.
로직, 화면·입력, Android 기기 성능을 각각 확인한다.
기획자는 재미와 분위기가 의도에 맞는지 플레이하며 판단한다.
현재 게임 프로젝트가 없어 빌드·플레이 검증은 수행하지 않았다.
