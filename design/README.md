## 보관

UX 기준은 저장소 문서에, 구현되는 UI 원본은 Godot Theme·공통 UI 씬에 둔다(D125). Godot 공통 UI의 구체 경로는 구현 시 기록한다. Figma는 화면 비교·협업이 필요할 때 선택적으로 사용하는 디자인 자료이며 기존 파일은 보존한다. 저장소에는 화면 ID, 기준 문서와 필요한 출력물을 보관한다. UX 규칙은 [화면 문서](../docs/05-ux/screen-flow.md), 첫 구현 범위는 [MVP](../docs/01-vision/scope.md)를 따른다.

Figma 페이지는 `00 Foundations / 01 Components / 02 MVP Flow & Wireframes`다. v0.3 [기본 스타일](https://www.figma.com/design/4MPq9ATTlOklMdtxgWVZnj?node-id=13-2)과 [공통 컴포넌트](https://www.figma.com/design/4MPq9ATTlOklMdtxgWVZnj?node-id=11-187)를 승인된 풍경 중심 방향으로 재작성했다. 이전 보드는 숨긴 ARCHIVE로 보존했다. Starter MCP 호출 한도로 최종 화면 검수와 PC·폰·폴드 적용 예시는 미완료이며 MVP 전체 흐름·와이어프레임도 후속 작업이다.

어셋 목록은 [asset-list.md](../docs/06-art-audio/asset-list.md), 편집용 원본은 `art/source/`, 게임용 출력은 `game/assets/`에 둔다. 현재 Figma 생성이 게임 UI 구현·배포를 의미하지 않는다.

[PC·폰·펼친 폴드의 자유 활동 화면 비교 시안](mvp/previews/README.md)을 추가했다. 생성 이미지로, 게임·Figma 화면 구현과 구분한다.

현재 진행 기준은 [UX 관리 방식](../docs/05-ux/workflow.md)이다. Figma 잔여 검수·적용 예시는 MVP 진행의 필수 선행 작업에서 제외한다.
