# 시스템 명세

- 상태: 초안 — Google 로그인 도입 확정
- 담당: 기획자 + AI
- 관련 문서: [MVP](../01-vision/scope.md), [명세 양식](../templates/system-spec.md)

채택한 시스템부터 문서로 만든다. MVP 포함 시점은 별도로 결정한다.

- [로그인과 계정](authentication.md): Google 로그인 직접 연동, 서버 외 운영비용 0원.
캠핑장, 배치, 모닥불, 요리, 인벤토리, 시간·날씨는 후보 예시다.
저장·불러오기는 진행 유지 필요성과 복원 범위를 정한 후 명세한다.

명세에는 목적, 입력·조건, 상태 변화, 데이터, 화면·소리, 예외, 저장 여부, 완료 조건을 포함한다.
모닥불이 채택된다면 점화 조건, 연료 소비 시점, 연료 소진, 중단·복원 규칙을 정한다.
구현자가 추측해서 빈칸을 채우게 두지 않고 결정 전에는 미정으로 표시한다.
