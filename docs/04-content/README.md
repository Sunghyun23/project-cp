# 콘텐츠

- 상태: 초안 — 종류와 개수 미정
- 담당: 기획자 + AI
- 관련 문서: [시스템](../03-systems/README.md)

채택한 시스템에 따라 items.md, recipes.md, locations.md 등을 작성한다.
콘텐츠마다 고유 ID, 이름, 역할, 연결 시스템, 에셋 참조를 정의한다.
속성·단위·기본값·허용 범위를 정하고 데이터가 늘면 실제 수치를 JSON·CSV 등으로 분리한다.

## 아이템 콘텐츠 방향

돈을 벌어 구매한 아이템으로 크고 화려한 캠핑장을 꾸미는 방향을 확정했다(D066). 기존 텐트·테이블·의자·조리·휴식 장비와 연결하되 실제 판매 목록·장식 종류·외형 변형 수는 별도로 정의한다. 아이템 등급·세트·뽑기·유료 판매를 이번 결정으로 추가하지 않는다.

아이템은 평일 준비 단계에서 구매하고 주말 캠핑장에서 배치한다(D070). 장소를 고를 때 게임 내 이용료를 내고 이번 방문에 사용할 캠핑 자리 크기를 선택한다(D104). 더 넓은 자리를 선택할 수 있으며 영구 토지 확장이나 현장 공간 확장 구매는 제공하지 않는다. 장비·차량 성장은 유지한다. 장소별 크기 선택 범위·칸 수·이용료·결제 시점·변경/취소/환불은 미정이다. 캠핑장에서는 아이템 상점을 열지 않는다. 실제 판매 목록과 구매 UI는 후속 정의한다.

구매 전 캠핑장에 놓인 모습과 캠핑장 점유 칸 수를 확인할 수 있어야 한다(D087). 아이템 콘텐츠의 외형·배치 크기와 운반 시 크기를 구분해 정의하며 구체 수치는 후속 작업이다.

D095에 따라 음식·재료는 소모 수량과 잔여 운반 크기를 구분한다. 구체 수량·차감 시점·포장·보존은 미정이다. 배고픔·졸음 효과(D096)를 개별 레시피에 부여할지는 상태 규칙 결정 후 정한다.

복잡한 음식을 먹을수록 만족도를 높게 반영한다(D099). 레시피 복잡도와 조리 품질·기존 별점·숙련을 구분해 정의한다. 복잡도 판정 기준·레시피별 만족도 수치와 효과는 미정이다.

## 장소 콘텐츠 방향

캠핑 장소마다 풍경과 배치 가능한 공간의 모양을 다르게 구성한다(D105). D104의 자리 크기 선택과 구분하며, 구체 장소 종류·개수·공간 형태·칸 수는 미정이다. 장소별 보너스·위험·날씨 효과는 이번 결정으로 추가하지 않는다. 장소별 콘텐츠를 정의할 때 풍경 자원과 배치 가능 영역을 연결한다. 호수·숲 등 구체 장소명이나 수량은 예시만으로 확정하지 않는다.

모든 캠핑 장소는 처음부터 선택할 수 있으며 장소별 이용료에 차이를 둔다(D106). 진행도·레벨 등 별도 장소 해금 조건은 두지 않는다. 실제 방문에는 이용료 지불이 필요하며 장소별 가격·잔액 부족 처리·자리 크기에 따른 가격 산정은 미정이다.

## 예약 가능한 장소의 추가·만석

새 장소가 추가될 수 있으며 무작위 만석을 도입한다(D111). 별도 장소 해금 없음(D106)은 유지하되 현재 제공되는 장소의 날짜별 예약 가능 여부를 따른다. 지역 수·추가 주체/시점·확률·예약 단위는 미정이다.
