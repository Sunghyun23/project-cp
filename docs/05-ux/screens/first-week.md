## 사용자 목적과 범위

선택한 캠퍼로 첫 월요일 업무에 들어가 수입을 얻고 주말 준비로 이어간다. 별도 로비를 거치지 않으며 첫 월요일 안내는 같은 화면에 짧게 제공한다. 신규는 캐릭터 선택 뒤 진입하고 기존 진행은 저장된 평일로 복귀한다. 같은 화면을 이후 평일·다음 주에도 재사용한다.

현재 UI는 단순 돈 벌기 체험에 한정한다. 상세 업무 미니게임·퇴근 시각/처리량 급여·알바는 이후 범위다. 기존 서버의 하루 한 번 버튼 업무·임시 수입/체력 수치를 유지하며 최종 시간 규칙을 구현했다고 보지 않는다. 이번 화면에서 알바 버튼은 제공하지 않으며 이전 API의 job 행동은 호환용으로 유지한다. 알바 도입 결정 자체를 취소하지 않는다.

## 화면과 행동

창밖 숲이 보이는 픽셀 업무 공간, 선택한 남성/여성 캠퍼의 대기 애니메이션, 현재 주차·요일·소지금·체력, 하단 안내와 `오늘 일 마치기`를 표시한다. 업무 공간은 AI 제작 시각 초안으로 최종 직장·업무 유형을 확정하지 않는다. 공통 도스필기 폰트·정돈된 천/숲색 Theme·HUD 칩·버튼·알림을 사용한다.

- 첫 월요일: 버튼으로 업무를 마치고 수입으로 캠핑을 준비한다는 짧은 안내.
- 업무 저장 중: 중복 입력 차단·처리 상태 표시.
- 성공: 실제 서버 응답 전후의 수입·체력 변화와 해당 요일을 표시하고 HUD를 갱신한다. 수입을 화면 표시 때문에 다시 지급하지 않는다.
- 결과 표시 후: 별도 확인 버튼 없이 다음 평일로 연결, 금요일은 기존 쇼핑 단계로 연결한다. 약 0.9초 결과 표시는 프로토타입 연출값이며 최종 시간 규칙이 아니다. 직전 결과 문구는 다음 행동 전까지 평일 화면에서도 확인 가능하다.
- 통신 실패/충돌: 일 마치기 버튼을 잠그고 저장 상태 재조회를 요구한다. 조회된 날짜·잔액을 기준으로 복구하며 무조건 재실행하지 않는다.
- 계정 버튼: 웹에서 기존 로그인/계정 페이지로 연결한다.

## 화면·입력 대응

폰은 제목 두 줄·가로로 배치한 핵심 HUD·하단 행동, 넓은 화면은 제목 한 줄과 같은 행동 구조를 사용한다. 배경은 화면을 채우면서 폰에서 책상 쪽을 보여주는 크롭을 사용한다. 터치/클릭 가능한 버튼과 키보드 UI 확인을 사용하고, 공통 `ui_input.gd`에서 패드 A·십자키를 등록한다. 기존 계정이 캐릭터 선택을 건너뛰어도 매핑을 적용한다.

구현: `game/ui/screens/first_week.tscn`·`.gd`, `game/ui/ui_input.gd`, `game/scripts/main.gd`. 아트: `game/assets/pixel/workroom-day.png`, 프롬프트는 같은 폴더의 `workroom-generation-prompt.json`.
