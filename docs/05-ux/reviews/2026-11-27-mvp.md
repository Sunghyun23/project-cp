## 실행 결과

- Java 서버 테스트 20개 통과, 실패·오류 0. 기존 인증·진행 호환과 새 MVP 규칙 포함.
- 로컬 Godot 클라이언트로 캐릭터 선택 → 평일 → 구매/예보/의상 → 출발 적재 → 현장 지면·테이블 위 배치 → 조리·먹기 → 취침 → 철거 → 귀가 미적재 손실 → 다음 주·재접속까지 통과. 키보드 이동 입력도 검사.

- 시드니 서버 HTTPS health의 API·DB 정상, index.pck HTTP 200 확인. 게임 파일 gzip은 빌드 원본과 일치.
- 공개 시드니 API에 별도 임시 세션으로 접속한 Godot 클라이언트도 전체 MVP·지면/테이블 배치·식사 소모·귀가 손실·다음 주·재접속 검증을 통과했다. 사용자 계정 진행은 사용하지 않았다.
- 실제 Chrome에서 새 인트로 → Google 로그인·계정 바로가기 → 공식 Google 로그인 버튼 표시 확인. 사용자 계정 인증 완료를 다시 실행한 것은 아님.
- 로그인 버튼이 인트로 뒤에만 있던 발견성 문제는 첫 화면 바로가기 추가로 수정·배포했다.

## 사용자 확인 — 배치 UX 미해결

직접 드래그 배포 후 사용자가 “X·Y·Z가 아니며 배치도 잘 안 된다”고 피드백했다. 현재 구현은 화면 드래그로 X/Z를 계산하고 Y를 지면/테이블로 자동 스냅하는 방식이다. 저장 좌표가 XYZ인 것과 사용자가 의도한 XYZ 배치 조작 경험을 구분해야 한다. 자동 입력·저장 검사는 통과했지만 사용자 배치 UX 검수는 통과하지 않았다. 정확한 화면 동작을 재현하고 원하는 XYZ 조작을 확인해 수정해야 하며, 현재 푸시는 수정 완료가 아닌 작업 보존이다.

## 2026-11-28 사용자 보완 및 공개 반영

- 캐릭터·장비 표시 크기와 픽셀 선명도를 보정했다. 절반 해상도 Viewport·캐릭터 선형 필터·전체 화면 bloom을 제거하고 실제 광원/그림자와 국소 효과를 유지했다.
- 풍경 감상 시 하단 대화상자를 숨기고 터치/클릭·Esc/뒤로가기·패드 A/B로 복귀한다. 감상 중에도 상단 낮밤/효과 조작이 가능하다. 낮밤 미리보기는 게임 날짜/시간을 바꾸지 않는다.
- 출발·귀가 모두 제한 시간 전에 끝낼 수 있다. 귀가 미적재품은 목록으로 손실을 확인한 뒤 종료한다. 자동 시간 종료는 유지한다.
- 드롭다운을 펼친 그림/칸 모양 목록으로 대체하고 마우스·터치 드래그로 적재/이동/회수한다. P/L/T/굽은 모양과 네 방향 회전·빈 칸 끼워 넣기를 서버 판정/저장에 연결했다. 구체 모양은 AI의 MVP 수치다.
- 서버 26개 검사, 실제 입력 이벤트의 UX·배치·광원 회귀 검사 통과. 공개 API 임시 세션에서 조기 출발·낮밤 배경/조명 전환·배치·식사 소모·조기 귀가 손실·다음 주·재접속 완주 검사 통과.
