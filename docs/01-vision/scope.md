# MVP 범위

- 상태: 초안
- 담당: 기획자 + AI
- 관련 문서: [콘셉트](concept.md), [제작 단계](../08-production/milestones.md)

## 목표

핵심 캠핑 경험 하나를 Android 기기에서 플레이하며 검증한다.

## 미정

필수·제외 기능, 콘텐츠 수, 플레이 시간, 목표 기기, 구체적 완료 조건은 아직 정하지 않았다.
텐트 설치 → 모닥불 → 요리 → 휴식은 가능한 흐름의 예시일 뿐 채택하지 않았다.
날씨·성장·수집·멀티플레이 역시 확정 기능이 아니다.

## 결정 방식

핵심 경험과 첫 플레이 흐름을 정한 뒤 기능을 `MVP 필수 / 이후 후보 / 제외`로 분류한다.
필수 기능에는 관찰 가능한 완료 조건과 필요한 에셋을 연결한다.
