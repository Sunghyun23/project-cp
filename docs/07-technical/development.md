# 개발 환경과 인계

- 상태: 초안
- 담당: AI, 기획자 검토
- 관련 문서: [기술 설계](README.md)

## 맥북 구성 계획

1. 로컬 폴더에 저장소를 clone한다.
2. 선택한 버전의 Godot을 설치한다.
3. 같은 버전의 Android export templates와 호환되는 JDK·Android SDK를 구성한다.
4. 경로와 export 설정을 구성하고 Android 테스트 빌드를 만든다.
5. 실제 기기 또는 에뮬레이터에서 실행한다.

정확한 버전과 명령은 엔진 버전 결정 후 확인한다. 현재 실행 가능한 프로젝트는 없다.
Mac의 실행 확인과 Android 기기 검증을 병행한다. APK는 테스트, AAB는 Google Play 배포에 사용할 수 있다.

## AI 검증

파일 수정·빌드·화면 캡처·기기 제어 가능 여부는 연결된 도구에 따라 다르다.
로직, 실행 화면, 기기 성능, 사람이 판단한 재미를 구분해 기록한다.
빌드 성공만으로 플레이 검증을 대체하지 않는다.
