# 완료 기준과 검증

- 상태: 초안 — 구체 시나리오 미정
- 담당: 기획자 + AI
- 관련 문서: [MVP](../01-vision/scope.md), [명세 양식](../templates/system-spec.md)

기능마다 다음을 작성한다.

- 선행 상태와 데이터.
- 플레이어 행동.
- 기대 상태 변화와 화면·소리 피드백.
- 실패·취소·앱 중단·재시작 결과.
- 검증 환경, 방법, 실제 결과.

결과는 `통과 / 실패 / 미실행`으로 구분한다.
로직, 화면·입력, Android 기기 성능을 각각 확인한다.
기획자는 재미와 분위기가 의도에 맞는지 플레이하며 판단한다.
로컬 프로토타입의 Godot 가져오기·Web 빌드와 PostgreSQL 기반 자동 테스트를 실행했다. [검증 기록](../07-technical/development.md)을 참고한다. 최종 MVP 완료 기준·15분 플레이 시간·Android 실기기·재미 검증은 미완료다.

## Android 화면 검증

[Android 화면·해상도 사양](../07-technical/android.md)의 검증 행렬을 적용한다. 일반 스마트폰·폴더블 커버·내부 화면의 표시·터치, 실행 중 접기·펼치기와 진행 유지·복원을 확인한다. 기종별 실제 해상도·밀도·앱 창 크기와 결과를 기록하며 현재는 모두 미실행이다.
