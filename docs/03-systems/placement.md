# 현장 배치 — 좌표·받침 속성

- 상태: 장소 좌표·stackable 요구 확정, 마름모 격자 편집·상판 장비 구분 로컬 반영
- 변경일: 2026-11-28
- 담당: AI 구현·문서, 사용자 방향·시안 검토

## 사용자 확정

2D 배경·2D 장비 이미지를 유지한다. 화면에는 마름모 격자를 표시하고, 저장과 충돌 판정은 기존 XYZ 좌표를 사용한다. **게임 좌표는 X/Y가 바닥 위치, Z가 높이다.** Godot 엔진 내부 좌표와 구분하며 `Vector3(game_x, game_z, game_y)`로 변환한다. 지면 또는 받침 위로만 놓으며 공중 부유는 허용하지 않는다. 큰 박스를 숨기고 물건 자체를 드래그한다. 장소마다 배치 좌표·금지 구역을 데이터로 기록하고 화면과 서버가 같은 범위를 사용한다.

`stackable`은 **다른 아이템을 위에 얹을 수 있는 받침인지**를 나타낸다. 테이블은 true, 텐트·의자·랜턴·버너·러그는 우선 false다. 위에 놓을 물건의 stackable 여부와 혼동하지 않는다. false인 물건에는 다른 아이템을 올릴 수 없다. 로컬 서버·클라이언트는 테이블 ID 전용 판정 대신 이 속성을 확인한다. 기준은 `server/src/main/resources/gameplay/item-surfaces.json`이며 게임용 복사본은 `game/data/item-surfaces.json`이다. 상판 높이·지지 범위가 함께 필요하며 자유로운 다단 쌓기의 도입을 뜻하지 않는다.

## 표시와 배치 규칙

- 편집 중에는 고정된 대각선 시점에서 마름모 격자를 보여준다. 장비는 직접 끌어서 놓고, 유효한 점유 범위는 초록색, 겹치거나 놓을 수 없는 범위는 붉은색으로 표시한다.
- 이동과 회전은 화면의 격자와 버튼으로 처리한다. 높이는 받침에 따라 자동 결정한다. 기존 저장 좌표와 서버의 좌표 형식은 유지한다.
- 기본 텐트는 현장 바닥에서 2×2 단위를 사용한다. 그림도 이에 맞춰 확대한다.
- 버너와 랜턴은 테이블에 완전히 들어가는 경우에만 자동으로 상판에 놓인다. 텐트·테이블·의자·러그는 바닥 전용이며, 바닥 장비끼리는 러그를 포함해 겹치지 않는다.
- 회전 및 완료 버튼은 편집 화면 하단에 표시해 장비를 가리지 않는다. 편집이 끝나면 격자와 배치 표시를 숨긴다.

## 장소 데이터

기준 원본: `server/src/main/resources/gameplay/campsites.json`. 웹 빌드 시 `game/data/campsites.json`으로 복사하며 서버 응답의 placement_site도 같은 원본을 사용한다. 현재 테스트 단위는 최종 미터 스케일이 아니다.

| 장소 | 게임 X 범위 | 지면 Z | 게임 Y 범위 | 금지 구역 | 받침 높이 Z |
|---|---|---|---|---|---|
| 호숫가 | 0~8 | 0 | 0~6 | 없음 | 테이블 0.9 |
| 소나무 숲 | 0~10 | 0 | 0~7 | X 0~1.4 / Y 0~1.4 나무 구역 | 테이블 0.9 |

아이템 중심뿐 아니라 전체 점유 범위가 허용 영역 안에 있어야 한다. 위 범위는 기존 MVP 테스트 수치를 문서화한 것이며 신규 장소 콘텐츠 확정과 구분한다.

## 좌표 변환·기존 저장 호환

장소 JSON schema_version=2는 X/Y 바닥·Z 높이로 기록한다. 클라이언트/서버는 엔진 계산 시에만 Y-up으로 변환한다. 새 드래그 요청은 `coordinate_system: z_up`을 명시하고 서버가 내부 좌표로 변환한다. 기존 무표시 요청·저장 field는 Godot Y-up 해석을 유지하므로 이전 진행을 이름만 바꾸어 잘못 해석하지 않는다. 응답의 `field_coordinate_system`으로 내부 저장 기준을 알린다. 사용자 좌표 표시와 시안은 Z-up이다.

## 현장 회전 요구

사용자 요구로 현장 아이템 회전을 지원한다. 회전 후 그림 방향·바닥 점유 범위·받침 범위를 함께 맞추고 저장/복원해야 한다. 현장 회전은 90도 단위(0°·90°·180°·270°)로 확정했다. 구체 조작 UI는 구현 후 검수한다. 방향별 그림 준비 기준은 [어셋 제작 규칙](../06-art-audio/asset-spec.md)을 따른다. MVP에 `회전 90°` 버튼·키보드 R·패드 Y를 연결했다. D167 이후 회전도 미리보기로만 적용하고 확정 후 캐릭터의 이동·설치가 끝나면 저장한다. 미배치품은 확정 전에는 설치되지 않는다. 경계/겹침/받침 판정이 실패하면 기존 방향을 유지하고 이유를 안내한다. 받침 위 물건이 있으면 먼저 내려놓아야 받침을 회전할 수 있다. 방향은 `rotation_degrees`로 저장하고 기존 `rotated`는 90/270도 여부로 유지해 호환한다. 예전 데이터의 true는 90도, false는 0도로 읽는다. 네 방향 그림은 2D 스프라이트로 교체하며 그림 자체를 기울이지 않는다.

## 확정·취소 후 캐릭터 설치 — D167

2026-11-28 사용자 확인으로 드래그를 놓을 때 바로 저장하던 흐름을 대체한다. `드래그 위치 미리보기 → 확정/취소 → 확정 시 캐릭터가 장비 옆으로 이동 → 손을 움직여 설치 → 서버 저장 성공` 순서다. 미확정 위치·회전 또는 이동/설치/저장 중에는 배치 완료로 다음 단계에 넘어갈 수 없다. 취소하면 신규품은 준비 위치로, 기존 설치품은 마지막 저장 위치·방향으로 돌아간다. 이동·손동작 중에도 저장 요청 전까지 취소할 수 있다. 저장 요청 이후 결과가 불명확하면 먼저 다시 조회한다. [상세·예외](../05-ux/screens/camp-actions.md)를 따른다.

### 텐트 안 침낭

침낭은 설치한 텐트의 바닥 안에 점유 면적이 전부 들어올 때만 놓을 수 있다. 침낭을 고르면 텐트를 반투명하게 보여 준다. 텐트를 옮기거나 철거하려면 침낭을 먼저 접는다. 텐트는 상판 받침으로 사용하지 않으며 다른 바닥 장비와의 겹침 금지 규칙도 유지한다.

## 가져온 짐 목록 — D202

미설치 장비를 캠핑장 안에 한꺼번에 띄우던 표시를 하단 접이식 `가져온 짐` 목록으로 대체한다. 사용자가 설명을 들은 뒤 이 방식으로 변경하는 데 동의했다. 목록에는 가져왔지만 아직 설치하지 않은 장비만 표시하며 음식·방수 겉옷은 현장 가구 목록에서 제외한다.

장비를 위로 끌면 목록이 접히고 선택품 하나만 미리보기로 나온다. 옆으로 넘기는 동작은 목록 스크롤이며 배치를 시작하지 않는다. 클릭·터치·키보드/패드 확인으로 선택한 뒤 현장 그림을 끌어 위치를 조절할 수도 있다. 미확정 후보가 있는 동안 다른 품목을 꺼내지 않고 먼저 확정/취소한다. 취소한 미설치 장비는 목록으로 돌아가며 현장에 잔상이 남지 않는다. 설치된 장비는 현장에서 직접 선택해 옮긴다. 확정 후 캐릭터 이동·손동작·한 번의 저장과 완료 전 다음 단계 차단은 D167을 유지한다.
