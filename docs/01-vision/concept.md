# 게임 콘셉트

- 상태: 초안 — 핵심 재미와 프로젝트 방향 확정, 세부 규칙 미정
- 담당: 기획자 + AI
- 변경일: 2026-11-27
- 관련 문서: [MVP](scope.md), [결정 기록](../decisions.md)

## 확정

캠핑 소재의 Android·웹 게임을 Godot으로 만든다. AI가 구현을 담당한다.
한 사람이 AI와 대화하며 기획하고 AI가 문서 대부분을 작성한다.

핵심 재미는 **돈을 벌어 아이템을 사고, 크고 화려한 캠핑장을 꾸미는 성장과 꾸미기**다(D066).

`돈 벌기 → 원하는 아이템 구매 → 캠핑장 꾸미기 → 달라진 캠핑장을 즐기기 → 다음 구매·꾸미기 목표`

평일 업무와 선택 알바는 아이템 구매를 위한 수입과 연결한다. 기본급만으로 기본 캠핑이 가능하고 알바는 추가 선택을 위한 수입이라는 D056은 유지한다. 요리·휴식·낮과 밤의 분위기는 꾸민 공간에서 즐기는 기존 활동으로 연결한다. 장비별 조리·휴식 효과와 레시피 숙련 규칙은 유지한다.

## 변경 이유와 검증

이전 AI 제안은 작은 캠프에서 요리하고 쉬는 만족감을 중심 재미로 가정했지만 확정되지 않았다. 사용자가 돈을 벌고 아이템을 사서 크고 화려하게 꾸미는 방향을 명시했으므로 그 가설을 이번 방향으로 대체한다.

현재 프로토타입은 장비 상당수가 배경에 포함되고 구매·배치가 압축되어 있어 이 핵심 재미를 아직 검증하지 못했다. 다음 검증은 적은 종류의 아이템이라도 수입·구매·배치가 연결되고 캠핑장이 달라지는 만족을 느끼는지 확인하는 방향을 제안한다. 구체 MVP 범위와 구현 착수는 별도로 정한다.

## 미정

- 캠핑장 배치를 다음 주에도 유지하는지, 매번 철수하고 다시 설치하는지. 기존 주간 철수 흐름과 새 꾸미기 목표의 관계를 우선 검토한다.
- 큰 캠핑장을 만드는 방식: 처음부터 넓은 공간인지, 별도 확장 규칙을 둘지. 토지 구매·단계별 확장은 아직 채택하지 않았다.
- 구매 가능한 아이템 종류·수량·가격, 구매 시점·화면, 보유·배치·저장 규칙.
- 대상 사용자, 한 번의 플레이 시간, 구체적인 반복 목표와 차별점.
- 최종 2D/3D, 카메라 시점, 세로/가로 화면, 전체 MVP, 온라인 기능 범위, 수익 모델.

## 다음 대화

꾸민 캠핑장이 주를 넘어 유지되는지부터 정하고 기존 설치·철수·짐 싸기 흐름과 맞춘다.
