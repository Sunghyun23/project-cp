- 변경일: 2026-11-28

- 근거: D165~D167. 사용자가 감상 중 이동, 의자 착석 스프라이트, 직접 걸어가 손을 움직이는 설치를 요청했다. 기존 조작과의 충돌을 설명한 뒤 감상 입력 변경과 확정/취소 흐름을 확인했다.

## 사용자 확정

- 감상 중 하단 메뉴를 숨겨도 캐릭터가 움직일 수 있다. 터치·클릭은 바닥 목적지 이동·의자 선택, 키보드·패드는 직접 이동에 사용한다. 종료 버튼·Esc·뒤로가기·패드 B로 메뉴를 복원한다.
- 의자를 사용하면 캐릭터가 다가가 앉는다. 실제 앉는 스프라이트를 추가하며 이동을 지시하면 일어난다.
- 장비는 드래그 후 확정 버튼을 표시한다. 확정하면 캐릭터가 해당 위치로 걸어가 손동작으로 설치한다. 미확정 상태로 다음 단계에 넘어갈 수 없고 취소할 수 있다.

## 구현 세부 — AI 프로토타입 선택

| 상태 | 표시·가능한 행동 | 저장·진행 |
|---|---|---|
| 위치 선택 전 | 기존 준비 물건/설치 물건을 드래그 | 서버 저장 없음 |
| 미리보기 | 반투명 위치·방향 미리보기, 확정·취소 표시. 다른 장비 선택은 확정/취소 후 | 서버 저장 없음, 배치 완료 비활성 |
| 이동·설치 | 장비 그림은 숨기고 목적지 점유 표시만 유지. 캐릭터가 장비 옆으로 이동해 1초 손동작. 취소 가능 | 배치 완료/다른 장비 조작 차단 |
| 저장 중 | 중복 확정·취소·다음 단계 차단 | `place_item`을 한 번만 요청 |
| 성공 | 캐릭터가 설치를 끝낸 장비를 서버 위치·방향으로 표시 | 배치 완료 가능 |
| 취소 | 신규 물건은 준비 위치, 기존 물건은 마지막 저장 위치·방향 복원 | 새 요청/추가 체력 차감 없음 |
| 오류·단계 변경 | 연출 중지, 저장 결과가 불명확하면 재조회. 서버 거절이면 기존 배치로 복원 | 자동 재요청 없음 |

회전도 즉시 저장하지 않고 미리보기→확정/취소로 처리한다. 기존 겹침·받침·금지 구역 검사를 사용한다. 장비 옆에 도달할 수 없으면 위치 변경 또는 취소를 안내한다. 캐릭터가 장비를 운반하는 별도 소품·펼쳐지는 장비 프레임·철거 애니메이션은 이번 요청으로 추가하지 않는다.

장소 경계·나무 구역·설치 물건의 바닥 점유를 피하는 0.25단위 경로를 사용한다. 캐릭터 속도 2.4단위/초·손동작 1초·의자 근처 확인 범위 2.5단위는 AI 테스트 수치다. 루프 연출의 종료가 저장 재시도를 일으키지 않는다. 숨긴 브라우저 탭/비활성 창과 저장 재조회 대기 중에는 캐릭터 연출을 정지한다.

의자 터치/클릭 또는 의자 근처 확인 키·패드 A로 착석한다. 의자 네 방향의 앉기 그림을 선택하고 좌석 기준점에 골반을 맞춘다. 앉기는 아이템을 받침 위에 배치하는 행동이 아니며 의자 stackable=false를 바꾸지 않는다. 별도 착석 회복 보상을 만들지 않고 기존 하루 1회 휴식 보상과 시간·STA 규칙을 유지한다.

이동 위치·앉기·설치 도중의 연출은 현재 클라이언트 세션 상태다. 재접속 시 서버의 마지막 설치 상태로 돌아온다. 저장 전 확정/이동/손동작만으로 설치가 서버에 반영되지 않는다. 저장 요청 후 연결이 끊기면 재조회로 반영 여부를 확인한다. 새로운 서버 장기 작업·오프라인 설치 기능을 도입하지 않는다.

## 구현과 검증

- `game/scripts/camp_actor.gd`: 이동 경로·접근·설치·착석 상태.
- `game/scripts/main.gd`: 실제 입력·캐릭터 표시·설치 완료와 저장 연결.
- `game/ui/screens/mvp_flow.gd`: 미리보기·확정·취소·진행 차단·감상 종료.
- `character_catalog.gd`·`camp_editor_3d.gd`: 캐릭터별 스프라이트·좌석 정렬.
- `tools/verify-camp-actions.gd`: 네트워크 없는 실제 Main 입력/연출/저장 요청 경계 검사.

macOS Compatibility GPU에서 `verify-camp-actions.gd`를 통과했다. 마우스·터치의 배치 미리보기/확정/취소, 설치 중 다음 진행 차단·취소, 걷기→손동작→한 번만 저장, 통신 실패 시 재조회, 회전 취소, 감상 중 터치 이동·실제 의자 클릭·키보드/패드 이벤트 이동, 앉은 뒤 이동, 네 방향·남녀/의상 조합, 비활성 시 연출 정지와 폰/폴드/PC 렌더링을 검사했다. 테스트는 비활성 OS 창에서도 입력 로직을 재현하도록 활성 상태를 주입하며 실제 물리 장치 검증과 구분한다.

기존 `verify-direct-placement.gd`의 겹침·테이블 받침·회전·버튼 위치 검사, `verify-camp-effects.gd`의 광원/그림자, `verify-night-background.gd`의 숲/호수 낮밤 검사도 통과했다. `verify-mvp-ux.gd`의 기존 트렁크 자동 드래그는 현재 macOS 실행에서 입력 재현에 실패했다. OS 포인터가 창 밖에 있는 상태였으며, 변경 전 `main`의 동일 검사에서도 요청이 발생하지 않는 것을 대조했다. 이번 변경의 회귀로 확인된 것은 아니며 해당 자동 드래그 검사를 통과했다고 보고하지 않는다. 실제 창에서 목록 선택은 확인했으나 네이티브 드래그 재검수는 남아 있다.

사용자 후속 지적 반영: 드래그/확정만으로 장비가 먼저 실제 설치된 것처럼 보이지 않는다. 미확정 후보는 반투명, 이동·설치·저장 중 후보 그림은 숨긴다. 기존 장비를 옮기는 경우 원래 설치본·광원은 저장 성공까지 이전 위치를 유지한다. 서버가 성공을 돌려준 뒤 새 위치에 실제 장비와 광원을 표시한다.
