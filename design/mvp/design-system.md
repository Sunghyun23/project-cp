# MVP 디자인 시스템

- 상태: v0.3 기본 스타일·컴포넌트 재작성 반영, 최종 화면 검수 미완료
- 변경일: 2026-11-27
- Figma: [기본 스타일](https://www.figma.com/design/4MPq9ATTlOklMdtxgWVZnj?node-id=13-2), [공통 컴포넌트](https://www.figma.com/design/4MPq9ATTlOklMdtxgWVZnj?node-id=11-187)

## 확정 방향과 제작안

D120의 풍경 중심 픽셀 캠핑장·작은 HUD·하단 행동 UI를 기준으로 재작성했다. 숲색, 크림색 천/종이, 나무 테두리와 따뜻한 불빛을 사용한다. 글자는 과도한 도트화보다 한국어 가독성을 우선한다. 최종 시점·화면 방향·게임 폰트를 확정하는 결정은 아니다.

현재 Figma 제작안은 Noto Sans KR를 사용한다. Display 32/Bold, Title 24/Bold, Heading 20/Bold, Body 16/Regular, Label 16/Bold, Caption 14/Regular, 숫자 20/Bold다. 기존 Pixelify Sans 숫자 스타일도 Noto Sans KR로 변경했다. 각진 2단위 테두리·3단위 단단한 음영, 4/8/12/16/24/32/48 간격, 최소 48 논리 단위 터치 목표를 기준으로 한다. 색과 간격은 CP Primitives → CP Semantic 변수 별칭으로 연결하고 공통 텍스트·효과 스타일을 사용한다.

## 재사용 컴포넌트

기존 Button, GridCell, Notice, Timer, ItemTile, HudChip, Panel을 수정하고 ActionButton, WeatherDay, CharacterChoice, ClothingChoice를 추가했다. 총 11개 계열·42개 변형/기본 컴포넌트와 픽셀 아이콘 11개다. 선택·포커스·비활성·처리 중·배치 가능/불가·시간 종료·손실 상태를 문구와 시각으로 구분한다. 반복 예시는 컴포넌트 인스턴스로 구성한다.

D121~D123의 의상 교체, 날짜별 예보, 첫 시작 캐릭터 선택을 포함한다. 캐릭터 초상은 임시 기호이며 실제 캐릭터 종류·외형·수량을 확정하지 않는다. 의상 부적합 체력 소모의 수치나 예보 기간도 확정하지 않는다.

## 화면 대응

폰은 상단 핵심 정보와 하단 행동, 펼친 폴드/PC는 풍경과 작업 영역을 함께 보여주는 방향이다. 풍경을 가리는 고정 사이드바를 반복하지 않는다. 터치·클릭·키보드·패드의 공통 행동과 포커스를 유지한다. 390×844·820×920·1280×720은 비교용 논리 프레임이며 최종 기기 사양이 아니다.

[생성 이미지 시안](previews/README.md)은 시각 방향 참고용이며 편집 가능한 Figma UI나 실행 화면이 아니다. 이전 Figma 기본 보드와 시안은 숨긴 ARCHIVE 보드로 보존했다.

## 검증과 남은 작업

컴포넌트 보드 스크린샷을 검토한 뒤 HUD/타이머 높이와 격자 글자 대비 등을 수정했다. 수정 후 스크린샷, 새 기본 스타일 보드의 화면 검수, 폰트·변수 바인딩 최종 감사는 남았다. Figma Starter MCP 도구 호출 한도로 PC·폰·폴드 적용 예시 생성 결과를 확인하지 못했으므로 완료로 집계하지 않는다.

세부 ID와 검증 상태는 [figma-state.json](figma-state.json)에 기록한다. 새 라이브러리 게시·Code Connect 매핑·게임 코드 적용·실제 기기 검증은 하지 않았다. D125로 작업 방식을 변경했다. 기존 Figma 자료와 미완료 기록은 보존하고, 앞으로는 저장소 화면 명세와 Godot Theme·공통 UI를 연결해 구현·검증한다. Figma 추가 작업은 선택 사항이다.

## Godot 공통 UI 초안 — v0.1

2026-11-27 디자인 시스템부터 만들어 보자는 사용자 요청으로 독립 전시 씬을 추가했다. 실제 플레이 화면에는 아직 적용하지 않았다. Figma 전체 컴포넌트를 모두 이식한 상태가 아니다.

- 테마: `game/ui/theme/camping.tres` — Noto Sans KR, 숲색 주요 버튼, 크림색 패널, 나무 테두리, 포커스·호버·눌림·비활성 상태.
- 재생성: `game/ui/theme/build_theme.gd`. 가변 폰트 굵기와 약한 embolden으로 가독성을 보정한 초안이다.
- 재사용 씬: `game/ui/components/action_button.tscn`, `paper_panel.tscn`. 부모의 공통 테마를 상속한다.
- 전시: `game/ui/showcase.tscn`, `showcase.gd`. 색·글자·버튼·HUD·예보/의상·적재/손실 표현을 비교한다. 버튼 클릭 피드백과 예보 토글은 전시용이다.
- 화면: 760 논리 단위 미만이면 한 열, 이상이면 두 열이며 긴 전시 내용은 세로 스크롤한다. 실제 플레이 화면 배치와는 다르다.
- 검증: Godot 4.7.2 구문 검사와 macOS Compatibility 실제 렌더링 캡처 확인. PC 1280×900 및 폰 크기 390×844에서 레이아웃을 확인했다. 폰 크기 확인은 글자 굵기 최종 보정 전이며 전체 스크롤·터치·키보드·패드 조작, 폴드 크기 및 Android 실기기는 미검증이다.

실행: 프로젝트 루트에서 `.tools/godot/Godot.app/Contents/MacOS/Godot --path game res://ui/showcase.tscn`.

[실제 Godot 전시 화면](previews/ui-system/showcase-pc.png). 수치·날씨·의상 문구는 시각 확인 예시이며 최종 게임 데이터가 아니다.

## 손글씨 도트 폰트 수정 시안 — D127

2026-11-27 사용자가 고딕보다 사람이 쓴 듯한 도트 느낌을 요청했다. Godot 전시 씬과 공통 테마를 **도스필기(DOSPilgi)** 시안으로 변경했다. 위 v0.1의 Noto Sans KR·embolden 설명은 이전 시안이며 Noto Sans KR는 현재 미지원 글자 폴백으로만 사용한다. Figma와 기존 플레이 화면은 변경하지 않았다.

16px 본문·32px 큰 제목, 안티앨리어싱과 서브픽셀 위치 비활성으로 원래 도트 획을 유지한다. 기존 호출의 14/20/21px도 전시 씬에서는 16px로, 24px 이상은 32px로 맞췄다. 폰트 임베딩 원본과 라이선스·제작자 출처는 `game/assets/fonts/DOS-fonts-README.md`에 기록했다.

[실제 수정 화면](previews/ui-system/showcase-handwritten.png). Godot 구문 검사와 PC 1280×900 실제 렌더링을 확인했다. 좁은 화면에서 커진 본문의 전체 배치·모든 글자 범위·Android 실기기 가독성은 미검증이다. 사용자의 긍정 피드백을 받아 후속 공통 UI도 이 글꼴로 진행한다. 실제 기기 가독성 검증은 남아 있다.

## 재사용 컴포넌트 정리 — v0.2

버튼·패널 외에 HUD 칩·선택 카드·체력 표시·적재 칸·알림을 각각 `.tscn`으로 분리했다. 선택/적재/불가/알림 스타일은 공통 Theme의 타입 변형을 사용하며 전시 씬은 실제 컴포넌트 인스턴스로 구성한다. Godot 컴포넌트는 7종으로, 앞의 Figma 11종 전체 이식과 구분한다.

원본 경로·설정 속성·테마 재생성 방식은 [Godot UI 안내](../../game/ui/README.md)에 기록했다. 수정 기준은 `build_theme.gd`이며 `camping.tres`도 저장소에서 관리한다. 도스필기 가져오기 옵션을 `.import`에 보관해 원본 글꼴을 외부 참조한다.

실행 검증·미검증 범위는 [검토 기록](../../docs/05-ux/reviews/2026-11-27-design-system.md)을 따른다. 실제 플레이 화면 적용은 다음 단계다.

## 캠핑 소품형 스킨 — D130

카드 같은 반듯한 박스라는 사용자 피드백을 반영해 기본 패널·버튼·선택 상태를 나무 테두리/팻말과 천 바탕으로 수정했다. `game/assets/ui/*.svg`는 직접 편집 가능한 도트형 벡터 원본이며 `tools/build-ui-skins.py`로 재생성한다. Theme는 StyleBoxTexture의 사방 16px 9-slice로 모서리·못·나뭇결을 보존하고 중앙만 늘린다. 테마를 재생성하기 전 신규 SVG를 Godot에서 가져와야 한다.

현재 캐릭터 선택 화면과 독립 전시 씬에서 이 공통 스킨을 사용한다. 기존 플레이의 별도 HUD 스타일 전체를 교체한 것은 아니다. 기본 카드형 색/단순 선 테두리 설명은 이전 시안이다. 선택된 버튼은 밝은 천·숲색 프레임·체크 문구로 표현하고 포커스는 별도 테두리로 구분한다. 기본/호버/눌림/비활성 스킨은 각각 분리했다. 알림·적재 상태는 기존 공통 상태 표현을 유지한다.

## 스킨 정돈 — D131

더 세련되게 다듬어 달라는 후속 피드백에 따라 D130의 두꺼운 나무 프레임·많은 못/나뭇결 장식을 줄였다. 현재 시안은 차분한 천색·숲색, 2px 수준의 얇은 경계, 단계형 도트 모서리와 작은 그림자를 사용한다. SVG 원본·Theme·컴포넌트 구조는 유지하며 StyleBoxTexture의 9-slice는 사방 **12px**로 변경했다(위 16px 기록은 이전 시안). 선택 UI는 `남성 / ✓ 여성`처럼 짧게 표시하고 확정은 `함께 떠나기`로 단순화했다. 손글씨 도트 폰트는 유지한다. 시각 승인·실기기 검증은 별도다.
