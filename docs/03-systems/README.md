## 현재 캠핑 반복 — D090~D091

매주 캠핑 장소를 선택할 수 있고, 주말마다 가져간 장비를 다시 펼쳐 캠프를 꾸민다(D090). 귀가 전에는 장비를 철거하고 트렁크의 격자 적재 퍼즐을 다시 한다(D091). 귀가 적재에 실패한 물건은 현장에 놓고 돌아온다. 차에 이미 남아 있는 미배치 물건과 철거한 물건을 어떻게 함께 적재 판정할지는 미정이다.

출발 적재에 못 실은 물건은 집에 남아 다음 주에 가져갈 수 있다(D076·D084). 귀가 적재에 못 실은 물건은 현장에 남는다(D091). 귀가 때 싣지 못한 물건은 잃어버린 것으로 처리하며 이후 회수할 수 없다(D093).

이 결정은 배치를 매주 유지하던 D067, 새 구매품만 운반하던 D073의 범위, 철거·귀가 적재가 없던 D079 및 D089의 해당 전제를 대체한다. 원하는 물건만 배치하는 D088, 격자 배치·트렁크 회전, 차량 교체 성장은 유지한다. 매주 사용할 기존 보유 장비도 출발 짐 싸기 대상이다.

장소를 고를 때 게임 내 이용료를 내고 이번 방문에 사용할 캠핑 자리 크기를 선택한다(D104). 더 넓은 자리를 선택할 수 있으며 영구 토지 확장이나 현장 공간 확장 구매는 제공하지 않는다. 장비·차량 성장은 유지한다. 장소별 크기 선택 범위·칸 수·이용료·변경/취소/환불은 미정이다. 장소는 게임 시간 기준 한 달 전부터 달력에서 예약한다(D109·D112). 현재 제공되는 모든 장소는 처음부터 비교·선택 가능하나 날짜별 예약 가능 여부를 따른다(D106·D111). 장소별 이용료에 차이를 둔다. 진행도·레벨 등 별도 장소 해금 조건은 두지 않는다. 실제 방문에는 이용료 지불이 필요하며 장소별 가격·잔액 부족 처리·자리 크기에 따른 가격 산정은 미정이다. 콘텐츠 수·철거 조작은 미정이다. 귀가 적재에도 시간 제한을 둔다(D092). 시간 종료 시 정상 적재한 물건만 가져오고 나머지는 현장에 남긴다. 귀가 적재는 한 번만 진행하며 재도전 없이 시간 종료 시 결과를 확정한다(D094). 구체 제한 시간·자동 귀가 여부는 미정이며 출발의 자동 전환 규칙을 귀가에 자동 적용하지 않는다.

## 수입·구매·캠핑장 꾸미기

돈을 벌어 장비를 확보하고 매주 고른 장소에서 화려한 캠프를 꾸민다(D066·D090). 금요일 아이템 쇼핑 → 메뉴·식재료 구매 → 출발 적재 순서이며 구매 없이 아이템 쇼핑을 넘길 수 있다(D086). 현장 아이템 상점은 제공하지 않는다. 구매 전 현장 외형·캠핑장 점유 칸 수를 확인하며 운반 크기와 구분한다(D087).

## 캠핑장 공간 확장

기존 현장 확장 구매(D068~D072)는 D104로 대체되었다.

### 방문할 캠핑 자리 선택

### 달력 예약·취소·예약 가능 여부 — D109~D111

예약 달력은 요일·현재 플레이 단계와 관계없이 언제든 열 수 있다(D113). 업무 후에만 접근하도록 제한하지 않는다.

게임을 플레이하는 동안 게임 시간은 계속 흐르며 예약 달력 등 화면을 열어도 멈추지 않는다(D114). 진행 중 적재 퍼즐의 제한 시간도 달력 열기로 정지하지 않는다. 게임 시간은 접속해 플레이하는 동안에만 진행하고 앱 종료·비접속 중에는 진행하지 않는다(D115). 게임 시간 속도·자동 날짜 전환·퇴근 시 업무량/급여 계산과 백그라운드/연결 끊김 판정·중단 복원 세부는 미정이다. 접속하지 않은 동안 예약일 경과·위약금 증가·생활 상태 변화를 오프라인 경과만으로 적용하지 않는다. 진행 중 적재 퍼즐의 중단/복원 규칙은 별도로 정한다.

- 달력을 보며 방문일 한 달 전부터 캠핑 장소를 예약할 수 있다(D109). 한 달은 게임 시간 기준이다(D112). 예약 창의 정확한 경계·방문 기간·동시 예약 수는 미정이다.
- 방문일이 가까워질수록 취소 위약금이 늘어나며 위약금을 반영해 환불할 수 있다(D110). 구간별 비율·금액·취소 마감·당일 취소·노쇼·예약 변경 규칙은 미정이다.
- 새로운 캠핑 장소가 추가될 수 있고, 장소가 무작위로 예약 만석이 될 수 있다(D111). 장소 추가 주체·시점과 만석 생성 시점·확률·예약 단위·재고 갱신 방식은 미정이다. 이미 확정한 예약을 무작위로 취소하는 기능은 채택하지 않는다.
- 현재 제공되는 모든 장소는 별도 진행도 해금 없이 비교·선택할 수 있다(D106). 다만 날짜별 예약 가능 여부·만석과 이용료 지불 조건은 따른다. 신규 장소 추가는 플레이어별 레벨 해금과 구분한다.

D103·D108의 금요일에만 선택/결제하고 곧바로 쇼핑으로 가던 전제는 대체한다. 금요일 아이템 쇼핑 → 식재료 구매 → 적재 퍼즐은 유지하되, 선예약 확인·변경·미예약/만석 상태를 금요일 준비와 어떻게 연결할지는 후속 정의한다. 무료 둘러보기와 명시적인 예약 확정 시 결제하는 방향은 유지하며 정확한 버튼·결제·환불 처리 UX는 후속 정의한다.

**UX 제안, 미확정:** 달력에 날짜별 예약 가능/만석/내 예약을 구분하고, 예약 전 이용료·선택 자리와 취소 규정을, 취소 전 현재 위약금·실제 환불액을 표시한다. 세부 화면 구성·오류/중복 결제 복구는 후속 정의한다.


장소 선택 화면에는 풍경 미리보기, 선택할 자리의 격자 모양·배치 가능한 칸 수, 이용료와 지불 후 남는 돈을 표시한다. 장소나 자리 크기를 바꾸면 해당 정보를 함께 갱신한다(D107). 달력에서 방문일·장소·자리 크기를 비교하고 명시적으로 예약을 확정할 때 이용료를 지불한다(D109, D108의 금요일 즉시 쇼핑 연결 대체). 둘러보거나 선택 후보를 바꾸는 동안에는 돈을 차감하지 않는다. 취소 시점에 따라 위약금이 증가하며 환불할 수 있다(D110). 구체 금액·결제 오류·예약 변경 세부는 미정이다. 구체 화면 배치는 후속 정의한다.

현재 제공되는 모든 장소는 처음부터 비교·선택 가능하나 날짜별 예약 가능 여부를 따른다(D106·D111). 장소별 이용료에 차이를 둔다. 진행도·레벨 등 별도 장소 해금 조건은 두지 않는다. 실제 방문에는 이용료 지불이 필요하며 장소별 가격·잔액 부족 처리·자리 크기에 따른 가격 산정은 미정이다.

장소를 고를 때 게임 내 이용료를 내고 이번 방문에 사용할 캠핑 자리 크기를 선택한다(D104). 더 넓은 자리를 선택할 수 있으며 영구 토지 확장이나 현장 공간 확장 구매는 제공하지 않는다. 장비·차량 성장은 유지한다. 장소별 크기 선택 범위·칸 수·이용료·변경/취소/환불은 미정이다.

캠핑 장소마다 풍경과 배치 가능한 공간의 모양을 다르게 구성한다(D105). D104의 자리 크기 선택과 구분하며, 구체 장소 종류·개수·공간 형태·칸 수는 미정이다. 장소별 보너스·위험·날씨 효과는 이번 결정으로 추가하지 않는다.

## 평일 업무와 선택 알바

퇴근 시간이 되면 당일 업무를 마감하고 처리한 업무량에 따라 급여를 받는다(D116). 모든 업무 완료를 다음 날 진행 조건으로 요구하던 D032의 해당 규칙은 대체한다. 퇴근 시각·업무량 집계·미완료 업무의 잔여 처리·기본급/성과급 구성·지급 시점은 미정이다. 알바 없이 기본 캠핑이 가능한 D056의 수입 설계는 유지하되 필요한 업무량·기본 수입을 수치로 검증한다.

- 물류 알바는 당일 업무 마감 후 참여 여부를 선택한다(D054·D116).
- 알바 기회는 매일 제공하며 하루 최대 1회다. 알바는 선택이고 같은 날 반복하지 않는다(D056).
- 기본급만으로 기본 캠핑을 진행할 수 있도록 비용·수입을 설계한다. 알바 추가 수입은 재료·장비 선택을 넓히는 용도다. 알바를 하지 않았다는 이유로 기본 캠핑을 막지 않는다(D056).
- 정확한 급여·알바 보상·장비·재료 비용, 기본 장비의 확보 방식, 실패·중단 시 횟수와 보상 처리는 미정이다. 기존 프로토타입의 가격·무료 대여를 최종 규칙으로 확정하지 않는다.
- 업무 결과는 작은 카드에 표시하고 알바 참여 여부를 선택할 수 있다. 별도 선택 카운트다운 여부와 날짜 전환의 세부는 미정이며 게임 시간은 멈추지 않는다(D114). 미참여 또는 알바 결과 표시 뒤에는 별도 확인·다음 날 버튼 없이 자동 진행한다(D055).

시간 목표·비교 방식은 [세션 흐름](../02-gameplay/session-flow.md), 화면은 [결과 카드 설계](../05-ux/screen-flow.md#평일-업무-결과-표시-제안)를 따른다.

## 장보기

금요일 장보기는 메뉴 선택 → 필요한 재료·총금액 확인 → 한 번에 구매 순서로 진행한다(D058). 구매 성공을 짧게 표시한 뒤 짐 싸기로 자동 전환한다(D059). 저녁 메뉴와 아침 커피·토스트 준비를 다룬다. 실제 재료 종류·수량·가격·개별 변경 범위와 구매 후 교환·환불·추가 구매는 미정이다. 구매 확인 전의 선택 변경과 이미 끝난 구매를 되돌리는 것은 구분한다.

화면과 예외 처리 제안은 [장보기 화면 흐름](../05-ux/screen-flow.md#장보기-흐름)을 따른다.

## 짐 싸기와 출발

매주 사용할 기존 보유 장비·새 구매품·식재료를 챙긴다(D090). 가져갈 물건은 트렁크 공간에 직접 배치해 짐을 싼다(D074). 단순 목록 확인만으로 완료하는 방식은 채택하지 않는다. 제한된 트렁크 공간에 물건을 맞춰 넣는 적재 퍼즐로 구성한다(D075). 구체 용량·겹침·회전 각도·크기·배치 판정·입력별 조작은 미정이다. 트렁크에 다 싣지 못한 물건은 잃지 않고 집에 보관하며 다음 주에 가져갈 수 있다(D076). 짐 싸기 대상에는 새로 산 물건뿐 아니라 이전 주에 집에 보관한 물건도 포함한다. 식재료의 소비·보존 세부 규칙은 별도 정의한다. D085로 D060의 직접 출발 선택을 대체한다. 적재 중에는 제한 시간 안에서 물건 배치를 조정한다. 필수 장비·적재 조건·준비 완료 판정과 출발 전 수정 범위, 이미 구매한 재료의 변경·환불은 별도 정의한다.

트렁크 적재 퍼즐도 격자 방식이며 물건을 칸에 잘 맞춰 넣어야 한다(D081). 트렁크에서는 물건을 회전해 배치할 수 있다(D082). 트렁크 칸 수·물건별 점유 형태·회전 각도·겹침·배치 판정과 입력별 조작은 미정이다. 캠핑장에 놓은 크기와 운반 시 점유 칸 수를 같게 할지는 별도 정의한다.

트렁크 적재 퍼즐에는 시간 제한을 둔다(D083). 시간이 끝나면 그때까지 정상적으로 적재된 물건만 이번 캠핑에 가져가고, 나머지는 집에 보관한다(D084). 제한 시간 수치·카운트 시작·일시정지·정상 적재 판정·재도전 규칙은 미정이다. 적재 시간이 끝나면 가져갈 물건·집에 남길 물건을 짧게 표시한 뒤 캠핑장으로 자동 출발한다(D085). 별도 출발 선택·결과 확인 버튼은 요구하지 않는다. 결과 표시 시간·전환 연출·저장 및 오류 복구의 세부는 후속 정의한다.

## 차량 크기와 적재 공간 성장

차량 크기도 성장·확장 대상으로 삼아 더 큰 차량으로 적재 공간을 늘릴 수 있게 한다(D077). 게임에서 번 돈을 모아 더 큰 차량으로 교체한다(D078). 차종·가격·교체 시점·추가 조건·단계 수와 기존 차량의 처리는 미정이다. 차량별 트렁크 크기·형태와 물건 크기의 관계는 적재 퍼즐 규칙에서 정의한다.

## 현장 설치와 자유 휴식

매주 현장에서 장비를 펼치며 가져온 물건 중 원하는 것만 캠핑장에 배치한다(D088·D090). 전부 배치하는 것을 자유 휴식 진입 조건으로 요구하지 않는다. 미배치 물건은 차에 둘 수 있으나 귀가 시 철거 물건과 함께 처리하는 적재 규칙은 별도 정의한다(D091).

현장 배치는 D134~D136으로 구체화했다. 2D 배경·2D 장비 스프라이트 위의 투명 3D 격자에서 X·Y·Z 위치를 조절하며, Y는 지면·테이블 위로만 맞춘다. 편집 중 격자를 옅게 표시하고 평소 숨긴다. 트렁크의 2D 격자 적재와 구분한다. [구현·임시 규칙](../07-technical/mvp-v1.md)을 따른다.

기획된 설치를 마치면 별도 설치 완료 화면 없이 같은 캠핑장에서 자유 휴식으로 이어진다(D061). 사용자는 풍경을 보거나 움직이다가 원할 때 저녁 준비로 넘어간다. 설치 완료를 확인하기 위한 추가 버튼·화면을 필수로 두지 않는다. 설치 완료 조건·배치 규칙·휴식의 구체 효과는 후속 정의한다.

## 주말 종료와 귀가·정산

귀가 전 장비를 철거하고 트렁크 격자 적재 퍼즐을 다시 한다(D090~D091). 귀가 적재 종료 시 못 실은 물건은 잃어버리며 이후 회수할 수 없다(D093). 귀가 퍼즐에도 시간 제한을 두고 종료 시 정상 적재한 물건만 가져온다(D092). 귀가 적재는 한 번만 진행하며 재도전 없이 시간 종료 시 결과를 확정한다(D094). 제한 시간 수치·기존 차 안 물건 처리·결과 후 전환은 후속 정의한다. 출발 시 집 보관과 구분한다.

## 요리

토요일 저녁 요리는 캠핑장 위의 조리 확대 화면에서 조작하고, 완성되면 화면을 닫아 같은 캠핑장으로 복귀한다(D062). 완성된 요리는 캠핑장으로 돌아온 뒤 사용자가 `먹기`를 눌러 식사를 시작한다(D063). 조리 완료만으로 자동 섭취하지 않는다. 섭취 효과는 실제 식사에 연결하고, 레시피의 첫 조리 기록은 기존 조리 규칙과 구분한다. 식사 후 회복량·레시피 변화를 짧게 보여주고 같은 캠핑장의 밤 불멍·별구경으로 자동 연결한다(D064). 구체 식사 연출·효과 반영 시점과 조리 중단 처리는 후속 정의한다. 화면 구성은 [조리 흐름](../05-ux/screen-flow.md#저녁-조리-확대-화면)을 따른다.

같은 요리를 만들 때 더 좋은 조리 장비를 사용하면 조리 시간이 짧아지고, 완성한 요리의 맛과 섭취 효과가 좋아진다.

조리 장비가 좋아질수록 사용할 수 있는 재료와 조리할 수 있는 레시피가 늘어난다. 라면 계열은 기본 장비에서 기본 라면으로 시작해, 장비를 갖추면 짜장라면·떡라면·만두라면 같은 변형을 만들 수 있고, 최상급 장비에서는 일본식 차슈라멘처럼 손이 더 가는 요리까지 만들 수 있다.

꼬치구이는 플레이어가 재료를 직접 골라 꼬치에 꽂고 굽는다. 재료 조합에 따라 먹었을 때 회복되는 스탯과 회복량이 달라진다. 같은 조합을 숯불로 구우면 가스불로 구웠을 때보다 맛과 섭취 효과가 좋아진다. 재료별 효과, 굽기 조작과 판정, 꼬치 조합의 레시피북 등록 단위는 미정이다.

레시피북은 첫 조리 결과를 별 1~3개로 기록한다. 별 3개에 도달하기 전에는 재조리 결과가 기록보다 좋을 때 별점을 갱신한다. 별 3개에 도달하면 조리 결과로는 별점이 더 이상 바뀌지 않고, 반복 조리로 해당 레시피의 숙련도만 오른다. 별 3개인 레시피의 숙련도까지 최대치에 도달하면 보너스 별 1개를 받아 총 4개가 된다.

숙련도가 오르면 해당 요리의 섭취 효과가 좋아진다. 요리마다 회복시키는 스탯과 회복량을 다르게 설정할 수 있다. 장비별 해금 조건, 별점 판정 기준, 숙련도 상승량, 레시피별 효과의 구체적인 수치는 미정이다.

일요일 아침에는 저녁과 같은 조리 확대 화면 방식을 사용해 커피와 토스트를 직접 준비한다(D065). 준비 순서·각 조작·완성 후 식사 및 철수 전환은 후속 정의한다. 커피는 믹스커피에서 시작해 드립커피와 원두 선택으로 확장한다. 토스트는 버터에 구운 기본 토스트에서 그릴 토스트, 오픈 토스트 등으로 확장한다.

## 음식 소모와 귀가 적재

음식은 직접 먹고 소모한다. 조리에 사용해 소모한 재료와 먹은 음식은 귀가 적재 대상에서 제외한다. 조리 도구·식기는 다시 챙길 물건이며, 남은 재료·먹지 않은 음식은 가져오려면 트렁크 공간을 차지한다(D095). 귀가 적재에 실패한 잔여 재료·음식도 D093의 손실 규칙을 따른다.

재료 차감 시점·인분/수량·남은 음식 단위·운반 포장·부패/보존 규칙과 도구·식기의 구체 목록은 미정이다. 소비된 음식이 장비처럼 귀가 짐에 남는 것으로 처리하지 않는다.

## 첫 시작 캐릭터 선택

첫 시작 시 캐릭터를 고를 수 있도록 첫 MVP에 포함한다(D123). 기존 인증·진행 조회 후 신규 플레이는 캐릭터 선택 → 첫 주 시작으로 연결하고 기존 진행은 저장된 캐릭터·단계로 이어간다. 첫 MVP 후보는 남성 1명·여성 1명이다(D128). 구체 외형·성능 차이·나중에 변경 가능 여부·상세 커스터마이징은 미정이며 현재 그림은 프로토타입이다. 의상 교체(D121)와 기본 캐릭터 선택을 구분한다. 프로토타입은 확정 시 캐릭터 ID와 첫 주 진입을 한 서버 행동으로 저장한다. 저장 응답이 불확실하면 조회 후 복구하며 기존 선택 필드 없는 진행은 재선택 없이 기존 외형으로 이어간다. 최종 저장 정책·계정 변경 UX는 후속 정의한다.

## 의상과 날씨 적합성

날짜마다 날씨가 다르며 일기예보로 미리 확인할 수 있다(D122). 예보 확인 → 날씨에 맞는 옷 준비/착용 → 부적합 시 STA 추가 감소를 MVP에서 연결한다. 날씨 종류·예보 가능 기간·정확도/변경 여부·하루 중 날씨 전환·날씨 확정 시점·예보 진입 화면은 미정이다. 날짜별 날씨를 매번 화면을 열 때 새로 뽑는 것으로 구현하지 않으며, 장소별 날씨 차이는 별도 정의한다.

MVP에서 옷을 갈아입을 수 있고, 날씨에 맞지 않는 옷을 챙겨가면 체력(STA)이 더 빨리 감소한다(D121). 의상 종류·수량·부위, 날씨 종류·하루 중 전환 여부, 적합성 판정·추가 소모량, 출발/현장 의상 변경 시점과 운반 크기는 미정이다. 첫 검증은 최소 의상·날씨 적합성 범위로 제한하며 대규모 의상 수집·날씨 시뮬레이션을 전제하지 않는다. 기존 배고픔의 STA 추가 소모와 함께 적용할 때의 계산은 후속 정의한다. 기본 체력 값이 필요하되 모든 생활 상태 페널티를 첫 MVP에 넣지는 않는다.

## 배고픔과 졸음

배고픔과 졸음 요소를 도입한다(D096). 기존 힘(STR)·행운(LUK)·체력(STA)을 대체하거나 같은 수치로 합치지 않는다. 상태의 수치 형태·발생/변화 조건·시간 기준·평일/캠핑 적용 범위·효과·저장 규칙은 미정이다.

배고플수록 설치·철거 같은 활동에서 체력(STA)을 더 소모한다(D098). 적용 활동의 전체 목록·발동 기준·추가 소모량·해소 및 회복 시점은 미정이다. 졸음 추가 페널티는 D102에 따라 역할 검토까지 보류한다.

**AI 제안, 미확정:** 배고픔은 음식 섭취로, 졸음은 취침으로 해소하도록 연결한다. 기존 음식의 스탯 회복·장비 효과와 어떻게 함께 적용할지는 다음 논의에서 정한다. 생존 실패·사망·이동 둔화·적재 시간 감소·커피의 졸음 해소 효과를 이번 요소 도입만으로 추가하지 않는다. D064의 사용자 취침 선택과 휴식 자동 종료 없음은 체력이 남아 있을 때 유지하며 STA 0 예외는 D100을 따른다.

## 음식의 복잡도와 만족도

손이 많이 가는 복잡한 음식을 먹을수록 만족도를 높게 반영한다(D099). 조리 완료만으로 섭취 만족도를 지급하지 않는다. 복잡도를 재료 수·공정·조리 난도 등 무엇으로 판단할지, 만족도의 수치·누적/유지·효과·표시 방식은 미정이다.

기존 맛·장비 효과·레시피 별점·숙련도를 만족도와 같은 수치로 간주하지 않는다. 복잡한 레시피와 조리 결과 품질을 어떻게 함께 반영할지는 후속 정의하며, 만족도가 배고픔 해소량이나 체력 회복량을 자동으로 늘린다고 확정하지 않는다.

## 불멍

식사 결과 표시 후 같은 캠핑장에서 불멍·별구경을 이어가며, 취침은 사용자가 원할 때 선택한다(D064). 체력이 남아 있을 때는 밤 휴식을 자동 종료하거나 최소 관람 시간을 강제하지 않는다. STA 0이면 D100에 따라 취침해야 한다.

토요일 밤에 불멍을 하면 사용하는 장비에 따라 휴식 효과가 달라진다. 장비별 효과와 회복 대상·수치는 미정이다.

## 캐릭터 스탯

핵심 스탯은 힘(STR), 행운(LUK), 체력(STA) 세 가지다. 힘은 장비 적재와 설치에, 행운은 채집과 확률 이벤트에, 체력은 활동에 쓸 수 있는 에너지에 영향을 준다. 기획서의 컨디션(CON)은 감기·열사병 같은 상태를 설명하는 항목이다.

평일 업무와 알바 미니게임으로 소모된 스탯을 캠핑에서 요리를 먹으며 회복한다. 활동별로 어떤 스탯이 얼마나 줄어드는지, 회복 상한과 컨디션의 세부 규칙은 미정이다.

체력(STA)이 0이 되면 토요일에는 취침해야 하고 일요일에는 귀가해야 한다(D100). 체력이 남아 있을 때의 사용자 취침·활동 선택은 유지한다. 일요일 STA 0이면 자유 활동은 종료하지만 철거·귀가 적재는 수행한다(D101). 0 도달 시 진행 행동의 정리·전환 시점, 취침 회복량, 철거·적재 중 체력 처리의 세부는 미정이다. 졸음 수치와 STA 0은 같은 조건으로 취급하지 않는다.

## 초기 난도와 재미 검증 — D102

초기 테스트는 적재 제한 시간·트렁크 여유 공간·체력 여유를 넉넉하게 설정한다. 체력 소진과 물건 손실 가능성은 사전에 명확히 알리고, 꾸미기·풍경 감상을 즐길 시간이 충분한지 확인한다. 졸음의 추가 페널티는 기존 체력과 역할이 겹치는지 검토할 때까지 보류한다.

왕복 적재 제한 시간·귀가 재도전 없음·미적재품 손실·체력 0의 요일별 종료는 유지한다. 구체 시간·칸 수·소모량·경고 기준은 플레이 테스트로 조정하며, 풍경 감상·배치 검토 중 자원 소모/정지 정책은 미정이다.

관찰할 항목은 적재 성공·손실 빈도, 실패 이유를 이해하는지, 반복하며 개선하는지, 꾸미기와 감상에 쓸 여유, 다음 캠핑을 하고 싶은지다. 수치 목표나 검증 통과를 아직 선언하지 않는다.

## 명세 작성

명세에는 목적, 입력·조건, 상태 변화, 데이터, 화면·소리, 예외, 저장 여부, 완료 조건을 포함한다.
불멍 상세 명세에는 점화 조건, 연료 소비 시점, 연료 소진, 중단·복원 규칙을 정한다.
구현자가 추측해서 빈칸을 채우게 두지 않고 결정 전에는 미정으로 표시한다.

- [현장 배치 좌표·stackable·표시 시안](placement.md): 장소별 허용 범위와 받침 속성, XYZ 격자/축 표시 검토.
