## 보관

Figma는 편집 가능한 디자인 원본이다. 저장소에는 파일·화면 ID, 기준 문서, 필요한 출력물을 보관한다. UX 규칙은 [화면 문서](../docs/05-ux/screen-flow.md), 첫 구현 범위는 [MVP](../docs/01-vision/scope.md)를 따른다.

Figma 페이지는 `00 Foundations / 01 Components / 02 MVP Flow & Wireframes`다. 현재 Foundations·재사용 컴포넌트와 픽셀 방향 보드는 생성했다. 사용자 피드백에 따라 일반 앱처럼 세련된 표현을 줄이는 중이며 시각 검토 완료본은 아니다. 와이어프레임 페이지는 아직 비어 있다.

어셋 목록은 [asset-list.md](../docs/06-art-audio/asset-list.md), 편집용 원본은 `art/source/`, 게임용 출력은 `game/assets/`에 둔다. 현재 Figma 생성이 게임 UI 구현·배포를 의미하지 않는다.
