신규 아이템·장소 제작과 기존 자원 수정은 [어셋 제작 규칙](asset-spec.md)에 따라 그림·메타데이터·게임 연결·검증 상태를 함께 기록한다.

## 매주 장소 선택·설치·철거·귀가 적재 — D090~D091

현재 제작 기준은 매주 선택한 장소에서 장비를 펼쳐 꾸미고 귀가 전 철거·격자 적재를 다시 하는 흐름이다. 이전 배치 영구 유지·철거 없는 귀가 전제는 대체되었다. 장소 종류·수량은 미정이며 임의로 지역 세트를 확정하지 않는다.

독립 장비의 설치/접힌 운반 상태, 2D 배경 위의 투명 3D 현장 배치 격자(D134~D136), 왕복 2D 트렁크 적재 영역·회전·점유 피드백이 필요하다. 캠핑장 격자는 평소 숨긴다. 구매 전 외형·캠핑장 점유 칸 수 미리보기를 제공한다. 운반 크기는 현장 크기와 구분한다. 구체 표현·규격은 제작 도출안이다.

출발 미적재 물건은 집에 남기고 귀가 미적재 물건은 현장에 놓고 온다. 귀가 때 못 실은 물건은 회수할 수 없는 손실이다(D093). 손실 물건의 결과 표시가 필요하며 현장 잔류물 회수용 자원·UI는 제작 대상이 아니다. 차량 크기별 자원 수·형태는 미정이다. 고정 캠핑장 영구 확장 대신 장소 선택 시 이용료를 내고 자리 크기를 선택한다(D104). 장소·자리별 사용 영역의 시각 구분이 필요하며 구체 종류·규격·별도 배경 수는 미정이다.

장소마다 풍경과 배치 가능한 공간의 모양이 다르다(D105). 풍경 자원과 실제 배치 가능 영역의 정합성을 확인해야 한다. 장소 선택의 풍경 미리보기·자리 격자 모양·배치 칸 수·이용료·예상 잔액 표시와 선택 변경 시 갱신은 확정(D107)이다. 구체 미리보기·경계 표현은 제작안이며 장소 세트 수·격자 규격·제외 영역 구성은 후속 정의한다.

## 음식·생활 상태 반영 — D095~D096

남은 재료·음식의 운반 상태·적재 점유가 필요하며 소모한 음식은 적재 자원에서 제외한다. 배고픔·졸음 표시와 관련 동작은 제작 도출안이다. 게이지 형식·경고·캐릭터 동작·구체 효과는 미정이므로 상태 종류 채택만으로 전부 제작하지 않는다.

배고픔에 따른 활동 STA 추가 소모(D098)와 복잡한 음식 섭취의 만족도(D099)를 피드백에 반영한다. 아이콘·효과·수치 표시 형식은 제작 도출안이며 구체 규칙 확정 후 선정한다.

## 달력 예약 반영 — D109~D111

한 달 전 예약·날짜별 만석·내 예약·취소 위약금/환불의 표시 자원을 검토한다. 구체 달력 UI·만석 표시·예약/취소 처리 피드백은 제작 도출안이다. 장소 추가는 가능하지만 추가 장소 세트를 임의로 확정하지 않는다.

## MVP 의상·날씨 적합성 — D121~D122

날짜별 날씨·일기예보 확인(D122), 옷 교체와 날씨에 부적합한 옷의 STA 추가 감소가 첫 MVP 범위에 포함된다. 예보의 날짜·날씨 아이콘/문구 표현이 필요하며 실제 종류·효과·자원 수는 후속 정의한다. 의상별 캐릭터 상태·옷 선택 미리보기·날씨 적합성/체력 효과 표시가 제작 도출안이다. 부위별 레이어/완성 스프라이트 방식과 종류·개수는 미정이다. 기본 대기·걷기에서 의상 교체 일관성을 확인한다.

## 첫 캐릭터 선택 — D123

첫 시작 시 기본 캐릭터를 선택한다. 선택용 외형 미리보기와 실제 플레이의 기본 대기·걷기/의상 교체 자원이 연결되어야 한다. 첫 MVP는 남성 1명·여성 1명(D128). 각 대기·걷기 4프레임씩의 프로토타입 시트를 연결했으며 최종 외형·상세 편집·실기기 검증은 남아 있다.

## 읽는 기준

현재 저장소의 기획·결정 기록·구현을 기준으로 필요한 시각 자원과 오디오 후보를 정리한다. 목록 작성 자체는 새 게임 기능이나 모든 항목의 제작 승인을 의미하지 않는다. 최종 MVP·2D/3D·시점·방향·콘텐츠 개수는 여전히 미정이다.

- **기획**: 기능·활동이 문서 또는 결정으로 채택됨. 표현 방식·세부 그림·동작은 아직 제작안이다.
- **프로토타입**: 현재 시각 실험에 한해 사용자가 요청했거나 임시 구현으로 채택함. 최종 게임 필수와 구분한다.
- **도출안**: 채택된 활동을 표현하기 위해 AI가 도출한 제작 단위. 실제 그림 대신 UI·기존 자원으로 표현할 수도 있다.
- **보류**: 문서 속 예시·확장 시점 미정·제안·미채택 시스템. 제작 대기열에 자동으로 넣지 않는다.

제작 상태는 `있음 / 부분 / 없음 / 코드 구현 / 외부 제공`으로 표시한다. `있음`도 프로토타입 결과이며 최종 납품 완료를 뜻하지 않는다. 표 한 행은 관리 단위이고 이미지 한 장·애니메이션 한 개·최종 수량과 같지 않다. 같은 소재를 배경·아이콘·조리 확대 화면에서 재사용할 수 있다.

## 장비와 소품

`접힘/설치됨` 등은 해당 활동의 시각 구분을 위한 제작안이다. 구체 모델 수·등급 수·가격·해금 조건을 확정하지 않는다.

## 제작 순서 제안

아래 순서는 AI 제안이며 전체 MVP·발주 수량 확정이 아니다.

1. **조작 가능한 캠핑장**: 빈 캠핑 자리와 텐트·테이블·의자·화로를 분리한다. 매주 설치·꾸미기·철거 결과가 실제 화면에 드러나게 한다(D090).
2. **현재 한 주의 핵심 음식**: 라면·꼬치구이·커피·토스트와 선정된 최소 재료·조리 상태를 제작한다. 저녁·아침 조리 확대 화면은 D062·D065로 채택했으며 화면 안의 손·도구·캐릭터 표현을 구체화한다.
3. **직접 조작 구간**: 업무 세 비교안·알바·트렁크 적재의 규칙을 정하고 필요한 화면·부품을 제작한다. 예시 그림을 먼저 전량 생성하지 않는다.
4. **보상·UI 정리**: 레시피북·별·숙련·효과 표시를 음식·장비 그림과 공통 UI로 연결한다. 로그인·로딩의 현재 자원은 재사용한다.
5. **품질·확장**: 채택한 광원 방식·기기 성능을 확인한 뒤 동작·이펙트·확장 레시피를 늘린다. 오디오는 도입을 결정한 뒤 별도 제작한다.

## 항목을 실제 제작으로 넘길 때

ID마다 `확정 범위 / 필요한 상태·방향 / 프레임·루프 / 실제 크기·피벗 / 원본·출력 경로 / 연결 씬·아이콘 / 출처·사용 조건 / 검수 결과`를 추가한다. 아직 정하지 않은 값은 미정으로 둔다.
2D 장비는 투명 배경과 같은 지면 기준점, 캐릭터는 프레임별 발 위치, 반복 효과는 루프 경계가 검수 항목이다. 3D는 메시·재질·광원·그림자 비용을 함께 본다. 모두 최종 규격 초안이며 수치 고정은 별도다.

목록 변경 시 같은 ID를 유지하고 근거·상태·재사용 관계를 갱신한다. 새로운 기획이 생기면 항목을 추가하며, 폐기된 항목을 이유 없이 완료로 바꾸지 않는다. `.godot`·빌드 결과·인증 정보는 어셋 납품물로 관리하지 않는다.
