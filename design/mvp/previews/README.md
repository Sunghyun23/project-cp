가로/세로와 비율은 이번 비교안이며 최종 화면 방향·지원 기종 사양을 확정하지 않는다. 같은 풍경·캐릭터·UI 스타일을 기준으로 따로 생성했으므로 실제 동일 월드의 카메라/좌표 일관성이 검증된 화면은 아니다. 배경·캐릭터·UI가 합쳐진 시안이며 독립 제작 어셋이나 편집 가능한 Figma 화면으로 세지 않는다.

PC는 넓은 풍경과 작은 하단 행동 그룹, 폰은 세로 카메라와 터치 가능한 하단 버튼, 폴드는 넓어진 장면과 여유 있는 하단 행동 그룹을 비교한다. 큰 사이드바는 사용하지 않는다. 모든 시안은 읽기 쉬운 한국어 글자와 도트 세계를 조합한다.

MVP에는 이후 요청으로 의상 교체·날짜별 날씨·일기예보·날씨 부적합 시 체력 추가 감소가 포함되었다(D121~D122). 이번 시안은 배치 비교를 위해 같은 옷·날씨를 사용하며 이 기능의 UI는 후속 작업이다. 초안의 소품·날짜·금액·시간은 최종 콘텐츠 확정이 아니다.
