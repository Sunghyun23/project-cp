# 콘텐츠

- 상태: 초안 — 종류와 개수 미정
- 담당: 기획자 + AI
- 관련 문서: [시스템](../03-systems/README.md)

채택한 시스템에 따라 items.md, recipes.md, locations.md 등을 작성한다.
콘텐츠마다 고유 ID, 이름, 역할, 연결 시스템, 에셋 참조를 정의한다.
속성·단위·기본값·허용 범위를 정하고 데이터가 늘면 실제 수치를 JSON·CSV 등으로 분리한다.

## 아이템 콘텐츠 방향

돈을 벌어 구매한 아이템으로 크고 화려한 캠핑장을 꾸미는 방향을 확정했다(D066). 기존 텐트·테이블·의자·조리·휴식 장비와 연결하되 실제 판매 목록·장식 종류·외형 변형 수는 별도로 정의한다. 아이템 등급·세트·뽑기·유료 판매를 이번 결정으로 추가하지 않는다.
