# 15분 세션 흐름

- 상태: 초안 — 15분 완주 목표와 진행 규칙 확정
- 담당: 기획자 + AI
- 관련 문서: [MVP](../01-vision/scope.md), [요리](../03-systems/README.md#요리), [전체 유저 플로우](../05-ux/user-flow.md)

핵심 반복의 목적은 돈을 벌어 아이템을 구매하고 크고 화려한 캠핑장을 꾸미는 것이다(D066). 아래 주간 순서는 기존 결정이며, 캠핑장 배치의 주간 유지 여부와 설치·철수의 관계는 재검토가 필요하다. 아이템 구매를 기존 식재료 장보기와 같은 화면·시점에 넣는지는 미정이다.

한 주의 첫 완주 테스트 목표는 현실 시간 약 15분이다. 게임 속 평일 5일과 토·일 1박 2일 캠핑을 한 번 진행한다. 표의 시간은 플레이 테스트 목표이며 세션에 시간 제한을 두지 않는다.

첫 방문에는 이 한 주를 시작하기 전에 짧게 캠핑 분위기를 경험한다(D045). 도입부와 실제 진행을 구분하며, 구성·시작/종료 흐름은 [전체 유저 플로우](../05-ux/user-flow.md)에 둔다. 도입부 시간의 테스트 목표 포함 방식은 미정이다.

평일에는 그날 배정된 사무 업무를 모두 끝내야 다음 날로 넘어갈 수 있다. 물류 알바는 당일 업무를 마친 뒤 선택한다. 평일의 다음 날 진행은 자동으로 한다(D054). 업무 결과를 작은 카드에 표시하고 알바 선택 때만 시간 제한 없이 멈춘다. 미참여 또는 알바 결과 표시 뒤에는 별도 다음 날 버튼 없이 자동 진행한다(D055). 구체 표현은 [평일 결과 설계](../05-ux/screen-flow.md#평일-업무-결과-표시-제안)에서 검토한다. 월~금 매일 업무 후 참여 여부를 선택할 수 있고 하루 최대 1회다(D056). 알바 없이도 기본급만으로 기본 캠핑이 가능하도록 설계한다. 알바 추가 수입은 재료·장비의 선택 폭을 넓히는 용도다. 금요일에는 알바를 하지 않기로 선택하거나 알바 결과 표시가 끝나면 별도 진행 버튼 없이 장보기로 자동 연결한다(D057). 결과 표시의 약 1~2초 목표는 검증해 조정한다. 캠핑 중 휴식은 자동으로 끝나지 않는다. 산책, 풍경 감상, 불멍, 별구경은 원하는 만큼 즐긴 뒤 화면의 `다음` 버튼을 눌러 다음 단계로 넘어간다. 바로 진행하고 싶을 때도 같은 버튼을 사용할 수 있다.

| 단계 | 목표 시간 | 플레이어 활동 |
|---|---:|---|
| 월~금 | 기준 3분, 알바 참여 횟수에 따라 변동 | 사무 업무 하루 약 30초씩 5일, 알바 1회 약 30초·하루 최대 1회 선택 |
| 금요일 장보기 | 1분 | 메뉴 선택 → 필요한 저녁·아침 재료와 총금액 확인 → 한 번에 구매(D058) → 완료 표시 후 짐 싸기로 자동 전환(D059) |
| 금요일 짐 싸기 | 1분 30초 | 장비를 골라 트렁크에 배치하고 준비가 끝나면 직접 `출발하기` 선택. 자동 출발하지 않음(D060) |
| 토요일 현장 설치 | 1분 30초 | 텐트 방향을 정하고 테이블과 의자 설치. 완료 후 별도 결과 화면 없이 같은 캠핑장의 자유 휴식으로 연결(D061) |
| 토요일 자유 활동 | 1분 | 산책하거나 풍경 감상 후 다음 단계 선택 |
| 토요일 저녁 | 2분 30초 | 캠핑장 위 조리 확대 화면에서 라면 또는 꼬치구이를 조리. 완성 시 같은 캠핑장으로 복귀(D062) → 사용자가 `먹기` 선택해 식사·스탯 회복(D063) |
| 토요일 밤·취침 | 1분 30초 | 식사 결과를 짧게 표시한 뒤 같은 캠핑장의 밤 휴식으로 자동 연결(D064). 불멍·별구경 후 사용자가 원할 때 취침 선택 |
| 일요일 아침 | 1분 | 저녁과 같은 조리 확대 화면에서 커피·토스트 직접 준비(D065). 초기 테스트는 믹스커피·버터 토스트 |
| 일요일 철수 | 1분 30초 | 텐트와 가구를 접고 장비를 차에 싣기 |
| 귀가·정산 | 30초 | 쓴 재료와 회복한 스탯을 확인하고 다음 주로 이동 |
| 합계 | 15분 | 한 주와 캠핑 1회 |

## 알바 선택과 시간 해석

D056으로 알바 기회는 월~금 매일 제공하고 하루 최대 1회, 한 주 최대 5회다. 선택은 의무가 아니다. `오늘은 쉬기`를 누르면 추가 확인 없이 자동 진행한다. 같은 날 알바를 끝내고 다시 참여하는 반복 경로는 두지 않는다. 시도·실패·중단 시 1회 소모 시점과 보상은 미정이다.

기존 15분 표는 알바를 한 주에 1회 참여하는 시험 사례로 유지한다. 참여 횟수 제한을 뜻하지 않는다. 아래는 업무·알바가 각 30초라는 현재 가정을 사용한 단순 합산이며 실제 측정 결과가 아니다.

| 한 주 알바 참여 | 평일 활동 합산 | 기존 전체 시간표의 예상 합계 |
|---|---:|---:|
| 0회 | 약 2분 30초 | 약 14분 30초 |
| 1회 | 약 3분 | 약 15분 |
| 5회 | 약 5분 | 약 17분 |

첫 인트로·결과 표시·선택 대기·사용자가 길게 쉬는 시간까지 포함한 실제 소요 시간은 별도 측정한다. 자동 종료·강제 제한으로 15분을 맞추지 않는다. 알바 참여별 시간과 반복 피로도를 함께 검증하고 필요하면 업무·알바 길이를 조정한다.

## 사무 업무 비교안

| 방식 | 조작 | 첫 테스트 분량 |
|---|---|---|
| 종이 넘기기 | 책상 위 서류를 한 장씩 스와이프해 처리한다. | 하루 4~6장을 출발점으로 삼아 실제 시간을 잰다. |
| 서류마다 미니게임 | 서류 한 장을 열면 짧은 게임이 하나 뜨고, 해결하면 해당 서류가 처리된다. 예를 들어 서류의 번호와 일치하는 도장을 찾는다. | 하루 1~2장부터 시작해 읽고 조작하는 시간을 잰다. |
| 서류 분류 퍼즐 | 서류의 아이콘을 보고 결제·배송·보관함 중 맞는 곳으로 끌어 넣는다. 잘못 넣은 서류는 책상으로 돌아와 다시 분류할 수 있다. | 하루 4~6장부터 시작해 실제 시간을 잰다. |

세 방식을 각각 월요일부터 금요일까지 플레이한다. 기본급과 체력 소모는 동일하게 적용하고, 각 방식의 하루 소요 시간과 닷새 동안의 반복 피로도를 비교한다. 하루 약 30초와 한 주 약 15분을 목표로 하며, 서류 장수와 최종 방식은 테스트 후 정한다.

## 밤 이벤트 제안

별이 많이 뜨는 밤에 별구경을 선택하면 가끔 별똥별이 지나간다. 별똥별을 본 뒤 소원을 빌면 행운이 오른다. 별이 많은 밤을 안내하는 방식, 출현 확률, 보상량, 다음 주 적용 범위는 플레이 테스트에서 정한다.
