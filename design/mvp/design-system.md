# MVP 디자인 시스템

- 상태: v0.2 시각 방향 검토 중 — 최종 디자인 미확정
- 변경일: 2026-11-27
- Figma: [컴포넌트](https://www.figma.com/design/4MPq9ATTlOklMdtxgWVZnj?node-id=5-86), [픽셀 방향](https://www.figma.com/design/4MPq9ATTlOklMdtxgWVZnj?node-id=8-73)

## 확정 방향

최소 디자인 시스템부터 만든 뒤 같은 구성요소로 MVP 전체 흐름·와이어프레임을 제작한다. 일반 앱의 매끈하고 둥근 카드보다 픽셀 캠핑 게임에 맞는 각진 창·버튼·격자를 사용한다. 최종 엔진 시점·전체 2D/3D·화면 방향을 확정하는 결정은 아니다.

## 현재 제작 초안

- 색: 숲색·종이/천색·나무색·따뜻한 모닥불색. 그라데이션·흐린 그림자보다 제한된 팔레트와 선명한 경계.
- 도형: 각진 테두리·계단형 프레임·눌리는 버튼. Figma의 기존 둥근 카드 초안을 수정 중.
- 폰트: Figma에서는 현재 Noto Sans KR와 Pixelify Sans를 사용했다. 한국어까지 도트 느낌이 필요하다는 사용자 피드백에 따라 Galmuri를 다음 비교 후보로 검토한다. 최종 폰트는 미확정이며 게임 폰트는 아직 교체하지 않았다.
- 크기: 본문·터치 목표를 작게 만들지 않는다. 4/8/12/16/24/32 간격과 48 논리 단위 터치 목표는 초기 제작안이다.
- 상태: 선택·포커스·비활성·처리 중·배치 가능/불가·시간 종료·손실을 색과 문구로 함께 구분한다.
- 구조: CP Primitives → CP Semantic 변수 별칭, 텍스트 스타일, 재사용 컴포넌트 인스턴스.

## 현재 Figma 컴포넌트

Button 12변형, GridCell 5변형, Notice 4변형, Timer 3변형, ItemTile 3변형, HudChip 2변형, Panel 1개와 픽셀 아이콘 4개. 제작 상태와 세부 ID는 [figma-state.json](figma-state.json)에 기록한다. 새 라이브러리 게시·Code Connect 매핑·게임 코드 적용은 하지 않았다.

## 화면 대응

폰은 상단 핵심 정보·하단 행동, 펼친 폴드/웹은 작업 패널과 세계를 병렬로 배치하는 초안이다. 기존의 풍경을 가리는 고정 사이드바를 반복하지 않는다. 터치·클릭·키보드·패드 공통 행동과 식별 가능한 포커스를 유지한다. 390×844·820×920·1280×720은 논리 프레임 비교안이며 최종 기기·화면 방향 사양이 아니다.

## 다음 작업

폰트·픽셀 창/버튼 방향을 사용자에게 비교 제시 → 시스템 수정 → MVP 전체 흐름·와이어프레임 → 검토 후 시각 어셋과 Godot 구현. Figma 스크린샷으로 기본 보드와 컴포넌트를 확인했으나 픽셀 수정의 전체 상태 검수와 실제 기기 검증은 남아 있다.
