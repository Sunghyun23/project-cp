## 추천안·미정

- Godot 4.7.2 + GDScript + Compatibility는 프로토타입 환경 기준으로 고정했다. Android 도구의 전체 구성과 최종 표현 방식은 미정이다.
- 저장소 UX 명세 → Godot 구현 → 플레이 검증을 반복한다(D125). Figma는 선택 도구이며 기존 자료는 [디자인](../design/README.md)에 보존한다.
- 2D/3D, 시점, 화면 방향, 최종 전체 MVP, 온라인 여부, 수익 모델 미정.
- 텐트, 날씨 등의 상세 규칙은 미정. 요리와 불멍은 관련 결정 및 시스템 문서 참고.
- 두 번째 참여자의 역할, 일정 미정.

- 웹 배포 주소·브라우저 지원 범위, 기기 간 저장 시점·동시 접속·충돌 규칙은 미정. 웹 제공 방향은 D017로 확정.

- ID·비밀번호 입력 규칙과 복구 코드 세부 정책은 미정. 복구 코드 도입은 D015로 확정. 자동 세션 유지와 사용자가 입력하는 인증 정보를 구분한다. 브라우저·기기 정보만으로 인증하지 않는다.
- Google 연결 대상에 이미 진행 데이터가 있는 경우의 처리와 연결 후 복구 코드의 유효 범위는 미정.
- 사용자가 ID·비밀번호 로그인을 끄는 기능은 추후 후보로 두며 현재 구현 범위에 포함하지 않는다.

- 초기 구성: 시드니 Lightsail 한 대에 Caddy + Java API + PostgreSQL. Java + Spring Boot는 D038로 확정했다. 기존 Django의 API·저장 형식을 유지해 전환한다. 별도 EC2 DB는 D036으로 초기 범위에서 제외하며 DB 분리가 필요해지면 재검토한다. 앱·DB 실행 관리에는 Docker Compose를 제안한다. [상세](07-technical/server-architecture.md)

- 초기 리전은 시드니, 기본 서버 요금은 월 $7이다. 별도 DB 인스턴스는 만들지 않는다. 백업·초과 트래픽·도메인 등을 포함한 총비용과 서울 이전 시점은 미정이다.
