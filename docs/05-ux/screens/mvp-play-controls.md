## 캠핑

`풍경 감상`을 누르면 하단 대화상자와 행동 버튼을 숨긴다. 화면 터치/클릭, Esc·뒤로가기·확인 키, 패드 A/B로 돌아온다. 복귀 입력은 이동/버튼 실행으로 중복 전달하지 않는다. 상단 상태·낮밤/효과 버튼은 유지한다. 기존 휴식 보상은 하루 한 번만 요청하며 이미 쉰 뒤에도 감상 화면에는 다시 들어갈 수 있다. 감상 중 게임 시간은 기존대로 흐르고 단계 변경·통신 오류 시 메뉴를 복원한다.

`낮`/`밤` 토글로 배경과 3D 조명을 미리 본다. 실제 날짜·시각·예보·체력·저장 상태는 변경하지 않는다. 현재 테스트 세션의 수동 선택을 유지하고 앱 재시작 시 실제 게임 시각 기준으로 돌아간다.

랜턴은 소유 목록에 있는 것만으로 빛나지 않는다. 현장에 설치하면 실제 OmniLight3D·국소 발광·그림자가 생기고 이동·테이블 위 높이·철거를 따른다. 그림 전체의 도트 윤곽을 가리는 과도한 bloom은 사용하지 않는다. 실제 Android GPU 품질/성능은 별도 검증한다.

## 출발·귀가 적재

- 드롭다운을 없애고 대상 물건의 전체 그림·점유 칸을 목록에 펼친다. 실은 물건에는 체크 표시를 한다.
- 그림을 트렁크로 끌어 놓는다. 실은 물건도 다시 끌어 옮기고 목록으로 끌어 빼거나 `빼기`를 사용한다. 터치·마우스와 선택→칸 확인 방식의 키보드·패드를 함께 지원한다.
- 회전 버튼/R/패드 Y는 0→90→180→270→0 순서다. 칸 모양·미리보기·판정·저장 방향이 함께 바뀐다. 불가능한 드롭은 저장하지 않는다.
- 출발/귀가 버튼은 스크롤 영역 바깥 하단에 고정한다. 폰에서는 짐싸기에 필요 없는 상단 제목·소지금·체력 박스를 숨겨 목록과 격자를 위한 공간을 확보한다.
- 제한 시간 전에 `출발하기`/`귀가하기`로 끝낼 수 있다. 출발 미적재품은 집 보관한다. 귀가 미적재품이 있으면 이름과 영구 손실을 보여주고 `계속 짐싸기` 또는 `남겨두고 귀가하기`를 선택한다. 귀가 손실 확인은 AI의 보호 UX 구현이다.
- 시간 종료 시에는 기존 자동 결과 확정·출발/정산을 유지한다. 조기 종료를 필수 추가 단계로 만들지 않는다.

## 테트리스형 점유 데이터

사용자 확정은 복잡한 칸 모양과 끼워 넣기다. 아래 배분은 AI의 MVP 테스트용이며 최종 장비 크기/난이도 확정이 아니다. 서버 `MvpRules.ITEMS`가 기준이고 응답 `item_catalog.cells`로 UI에 전달한다. 현장 3D 점유/받침과 트렁크 2D 칸은 구분한다.

| 아이템 | 기본 점유 칸 (X,Y) | 모양 |
|---|---|---|
| 텐트 | (0,0) (1,0) (2,0) (0,1) (1,1) | P형 5칸 |
| 의자 | (0,0) (0,1) (1,1) | L형 3칸 |
| 테이블 | (0,0) (1,0) (2,0) (1,1) | T형 4칸 |
| 러그 | (0,0) (0,1) (1,1) (1,2) | 굽은 4칸 |
| 버너·랜턴 | 각 2칸 | 작은 직선형 |
| 라면 재료 | (0,0) | 1칸 |

사각형 외곽이 아니라 실제 점유 칸끼리 충돌 검사한다. 기존 그림을 테트리스 모양으로 찌그러뜨리지 않고 목록에는 원래 물건 그림과 칸 모양을 함께 표시한다. 기존 사각형에서 칸을 줄이는 방식이라 보관된 적재품의 범위를 확장하지 않는다. 이전 `rotated` 저장도 읽되 새 요청은 `rotation_degrees`를 저장한다.
