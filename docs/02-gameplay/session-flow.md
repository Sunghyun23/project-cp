# 15분 세션 흐름

- 상태: 초안 — 15분 완주 목표와 진행 규칙 확정
- 담당: 기획자 + AI
- 관련 문서: [MVP](../01-vision/scope.md), [요리](../03-systems/README.md#요리)

한 주의 첫 완주 테스트 목표는 현실 시간 약 15분이다. 게임 속 평일 5일과 토·일 1박 2일 캠핑을 한 번 진행한다. 표의 시간은 플레이 테스트 목표이며 세션에 시간 제한을 두지 않는다.

평일에는 그날 배정된 사무 업무를 모두 끝내야 다음 날로 넘어갈 수 있다. 물류 알바는 선택 활동이다. 캠핑 중 휴식은 자동으로 끝나지 않는다. 산책, 풍경 감상, 불멍, 별구경은 원하는 만큼 즐긴 뒤 화면의 `다음` 버튼을 눌러 다음 단계로 넘어간다. 바로 진행하고 싶을 때도 같은 버튼을 사용할 수 있다.

| 단계 | 목표 시간 | 플레이어 활동 |
|---|---:|---|
| 월~금 | 3분 | 사무 업무 하루 약 30초씩 5일, 선택 물류 알바 1회 약 30초 |
| 금요일 장보기 | 1분 | 저녁 메뉴와 아침 재료를 고르고 장보기 |
| 금요일 짐 싸기 | 1분 30초 | 장비를 골라 트렁크에 배치 |
| 토요일 현장 설치 | 1분 30초 | 텐트 방향을 정하고 테이블과 의자 설치 |
| 토요일 자유 활동 | 1분 | 산책하거나 풍경 감상 후 다음 단계 선택 |
| 토요일 저녁 | 2분 30초 | 라면 또는 꼬치구이를 한 가지 만들고 먹어서 스탯 회복 |
| 토요일 밤·취침 | 1분 30초 | 불멍이나 별구경을 즐긴 뒤 취침 선택 |
| 일요일 아침 | 1분 | 믹스커피를 타고 버터 토스트 굽기 |
| 일요일 철수 | 1분 30초 | 텐트와 가구를 접고 장비를 차에 싣기 |
| 귀가·정산 | 30초 | 쓴 재료와 회복한 스탯을 확인하고 다음 주로 이동 |
| 합계 | 15분 | 한 주와 캠핑 1회 |

## 사무 업무 비교안

| 방식 | 조작 | 첫 테스트 분량 |
|---|---|---|
| 종이 넘기기 | 책상 위 서류를 한 장씩 스와이프해 처리한다. | 하루 4~6장을 출발점으로 삼아 실제 시간을 잰다. |
| 서류마다 미니게임 | 서류 한 장을 열면 짧은 게임이 하나 뜨고, 해결하면 해당 서류가 처리된다. 예를 들어 서류의 번호와 일치하는 도장을 찾는다. | 하루 1~2장부터 시작해 읽고 조작하는 시간을 잰다. |

같은 기본급과 체력 소모로 각각 5일을 플레이해 하루 소요 시간과 반복 피로도를 비교한다. 하루 약 30초은 목표치이며, 서류 장수와 최종 방식은 테스트 후 정한다.

## 밤 이벤트 제안

별이 많이 뜨는 밤에 별구경을 선택하면 가끔 별똥별이 지나간다. 별똥별을 본 뒤 소원을 빌면 행운이 오른다. 별이 많은 밤을 안내하는 방식, 출현 확률, 보상량, 다음 주 적용 범위는 플레이 테스트에서 정한다.
