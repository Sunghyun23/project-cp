# 제작 단계

- 상태: 초안 — 일정·상세 범위 미정
- 담당: 기획자 + AI
- 관련 문서: [MVP](../01-vision/scope.md), [완료 기준](acceptance.md)

| 단계 | 결과물 | 다음 단계 조건 |
|---|---|---|
| 기획 기반 | 콘셉트, MVP, 흐름, 시스템 명세 | 첫 플레이의 입력·결과·완료 조건 정의 |
| 환경 구성 | 버전 고정 Godot 프로젝트, Android 빌드 | 선택한 기기에서 실행 |
| 프로토타입 | 임시 에셋의 작은 플레이 사이클 | 핵심 행동과 반복 플레이 검토 |
| MVP | 채택한 기능과 에셋 | 합의한 완료 기준과 기기 검증 충족 |

현재 기획 기반 단계다. 일정·세부 역할·배포 시점은 정하지 않았다.
작업과 버그는 GitHub Issues로, 규칙과 설계 의도는 문서로 관리한다.
