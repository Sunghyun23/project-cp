## 확정 요구

Android 앱은 일반 스마트폰과 폴더블 기기를 지원한다. 일반 스마트폰 화면, 폴더블의 접힌 상태에서 사용하는 커버 화면, 펼친 상태의 내부 화면에서 각 화면의 해상도와 화면 비율에 맞게 표시·조작할 수 있어야 한다.
하나의 고정 해상도만 지원하는 방식으로 구현하지 않는다. 이 요구는 최종 2D/3D·카메라 시점·세로/가로 방향 결정을 대신하지 않는다.

게임은 터치·마우스 클릭·키보드·게임패드 입력을 모두 지원하는 요구가 있다(D048). 터치·클릭은 목적지 이동, 키보드·패드는 직접 이동이며 웹과 공통 인터페이스를 사용한다(D049). 입력별 구체 매핑·장치 연결·플랫폼별 검증 범위는 [조작 명세](../02-gameplay/controls.md)에서 구체화한다. 현재 네 입력 전체의 구현·호환성 검증 완료를 의미하지 않는다.

## 화면 대응 기준

- 물리 픽셀 해상도, 화면 비율, 화면 밀도와 앱에 실제로 할당된 창 크기를 구분한다. 기종 이름이나 픽셀 수 하나만으로 UI 배치를 고정하지 않는다.
- 좁고 긴 커버 화면부터 넓은 내부 화면까지 글자·버튼·HUD·대화창·핵심 게임 영역이 잘리거나 겹치지 않아야 한다. 단순 축소로 글자와 터치 영역이 사용하기 어려울 만큼 작아지지 않게 한다.
- 화면이 넓어지면 여백·정렬·패널 배치를 조정한다. 여백이나 게임 영역의 확장 방식은 최종 시점·화면 방향을 정할 때 구체화한다.
- 화면에 표시된 버튼·드래그 대상과 실제 터치 좌표가 해상도·크기 변경 후에도 일치해야 한다.
- 카메라 구멍·노치·시스템 표시 영역과 제스처 영역을 고려한다. 기기가 가림 영역이나 화면 분할 경계를 제공하는 경우 핵심 정보·조작을 가리지 않게 처리한다. 구체적인 Godot·Android 연동 방식은 구현 전 검증한다.
- 앱 실행 중 접기·펼치기와 사용 화면 전환, 창 크기 변경에 대응한다. 화면 전환만으로 계정·진행 상황을 잃거나 행동·보상이 중복 처리되지 않아야 한다.

## 검증 행렬과 완료 기준

| 환경 | 확인할 항목 | 현재 결과 |
|---|---|---|
| 일반 스마트폰 | 지원 범위의 서로 다른 해상도·밀도·화면 비율에서 표시·터치·드래그 | 미실행 |
| 폴더블 커버 화면 | 좁은 가로 폭에서 핵심 UI·텍스트·버튼 접근 | 미실행 |
| 폴더블 내부 화면 | 넓은 화면에서 배치·가독성·게임 영역 표시 | 미실행 |
| 실행 중 접기·펼치기 | 화면 재배치, 터치 좌표, 진행 유지·복원과 중복 요청 방지 | 미실행 |
| 창 크기 변경 | 지원하는 창 크기 범위에서 잘림·겹침·입력 불일치 방지 | 미실행 |

대상 기기를 정하면 각 행에 실제 기종, Android 버전, 물리 해상도(px), 밀도, 앱 창 크기, 방향과 결과를 기록한다. 같은 기기의 화면 해상도 설정이 여러 가지라면 지원할 설정도 기록한다.
에뮬레이터의 레이아웃 검사와 Android 실기기의 입력·화면 전환·성능 검증을 구분한다. 데스크톱 브라우저 크기 변경만으로 폴더블 지원 완료로 판정하지 않는다.

## 미정

- 지원 기종과 폴더블 형태, 최소 Android 버전.
- 최소·최대 지원 픽셀 해상도, 화면 비율·밀도·창 크기의 구체적인 범위.
- 세로/가로 지원 정책, 논리 기준 해상도, UI 배율·최소 터치 크기와 글자 크기.
- 멀티 윈도우·분할 화면의 지원 범위와 폴더블을 중간 각도로 펼치는 자세 전용 UI의 도입 여부.
- 저사양·일반·폴더블 기기의 프레임률·메모리 목표.

현재는 요구사항을 문서화한 단계다. Android 빌드·기기별 해상도·접기·펼치기 동작은 아직 검증하지 않았다.

## 프로토타입 UI 확인 (2026-11-27)

사이드바를 제거하고 상단 주차·스탯·계정·보기 메뉴와 하단 행동 카드를 분리했다. 일반 폰은 하단 중앙, 펼친 폴드는 오른쪽 아래, 넓은 웹·짧은 가로 화면은 왼쪽 아래에 작은 카드를 둔다. 행동이 많으면 2열과 스크롤을 사용한다. 브라우저 390×844·820×920·1280×720에서 배치와 풍경 노출을 확인했으며 실제 Android·폴더블 접기/펼치기는 아직 미검증이다. 실제 3D 광원 데모는 별도 보기 옵션이며 Android GPU 성능 측정이 필요하다.
