# SC-CHARACTER-SELECT 검토

- 일자: 2026-11-27
- 대상: 작업 트리의 캐릭터 선택·공통 스킨 변경(커밋 전)
- 환경: macOS · Godot 4.7.2 Compatibility · 로컬 Java API/PostgreSQL

## 확인한 결과

- 서버: 독립 테스트 DB에서 `bash tools/test-server.sh` 실행, 총 14개 통과. 선택 전 업무 거부·잘못된 후보 거부·중복/오래된 확정 거부·선택 저장/조회·다음 주 유지·기존 캐릭터 필드 없는 데이터 호환·쿠키 계정의 다른 브라우저 복원을 포함한다.
- 클라이언트: `tools/verify-character-select.gd`와 실제 로컬 API를 함께 실행. 선택 전 확정 비활성 → 마우스 입력 이벤트로 여성 → Enter 입력 이벤트로 남성 → 통신 실패 시 선택 보존·재확정 제한 → 조회 복구 → 패드 A 입력 이벤트로 확정 → 첫 월요일 진입 → 새 클라이언트에서 선택/진행 복원 통과. 별도 임시 세션과 임시 설정 경로를 사용해 기존 로컬 진행을 덮어쓰지 않았다.
- 화면: PC 1280×900, 폰 크기 390×844, 펼친 폴드 크기 820×920의 실제 렌더링을 확인했다. 큰 패널 두 개의 초안은 풍경 전체와 하단 안내판으로 대체했다. 남성/여성 시트는 미리보기와 플레이에서 공유한다.
- 공통 스킨: 초기 두꺼운 목재 장식은 후속 피드백으로 얇은 테두리·차분한 천/숲색·작은 픽셀 모서리로 수정했다. 현재 원본의 9-slice 테두리는 12px다.

## 제한과 남은 확인

입력 이벤트 자동 검사는 실제 물리 키보드·패드·Android 터치 검증과 다르다. Android 실기기·접기/펼치기·안전 영역·여러 화면 비율·웹 로그인부터의 브라우저 실제 조작은 미검증이다. 웹 빌드 성공 여부는 별도 실행 결과로 기록한다. 공개 서버 배포·Git 푸시는 이번 작업에서 수행하지 않는다. 기본 외형은 프로토타입이며 의상 교체는 아직 구현하지 않았다.

검사 과정에서 Godot headless 에디터의 macOS 인증서 조회/샌드박스 밖 설정 저장 오류가 있었으나 에셋 가져오기가 완료됐고 일반 실행의 렌더링과 입력/저장 검사는 정상 종료했다.
