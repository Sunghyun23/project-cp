# 대화 기반 기획

- 상태: 확정 — 사용자가 설명한 작업 방식
- 담당: 기획자 + AI
- 관련 문서: [목차](../README.md), [결정 기록](../decisions.md)

## 역할

한 사람이 AI와 대화하며 아이디어·요구사항을 설명하고 방향을 정한다.
AI는 질문·선택지·추천 이유를 제시하고 문서 대부분을 작성·갱신한다.
초기 참여자는 두 명이지만 문서마다 두 사람의 합의를 요구하지 않는다. 두 번째 참여자의 역할은 미정이다.

## 진행

1. 기획 시작·재개 의도를 파악하면 기존 문서를 확인하고 AI가 질문을 주도한다. 한 번에 한 주제와 핵심 질문 하나를 기본으로 하고 답을 기다린다.
2. AI가 내용을 정리하고 필요한 질문과 구체적인 초안을 제시한다.
3. 명확한 결정은 해당 문서에 반영한다. 사소한 초안마다 승인을 요구하지 않는다.
4. AI 제안과 미결정 사항을 확정 내용과 구분한다.
5. 결정 변경 시 영향을 확인하고 관련 문서·결정 기록을 갱신한다.
6. 반영한 문서와 남은 중요한 질문을 짧게 알린다.

기본 질문 순서는 콘셉트·핵심 경험 → 대상 사용자·플레이 상황 → 표현 방식 → 반복 구조·첫 플레이 → MVP → 시스템·콘텐츠 → UX·아트·오디오 → 기술 제약·완료 기준이다. 답변과 기존 결정에 따라 순서를 조정한다. 자세한 질문 규칙은 [AGENTS.md](../../AGENTS.md)를 따른다.
작은 플레이 단위로 기획·설계·구현·검증을 반복한다. Figma는 모든 작업의 필수 선행 단계가 아니다.
대화의 예시를 기능으로 확정하거나 문서에 없는 기능을 임의로 추가하지 않는다.
