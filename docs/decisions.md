## 추천안·미정

- Godot 4 안정 버전 + GDScript는 추천안. 버전·언어 확정 전.
- Figma는 UI·흐름·아트 설계 도구로 논의. 링크와 필수 범위 미정.
- 2D/3D, 시점, 화면 방향, 핵심 재미, MVP, 온라인 여부, 수익 모델 미정.
- 텐트·모닥불·요리·날씨·성장 등은 예시·후보.
- 두 번째 참여자의 역할, 일정 미정.

- 웹 제공 방식과 게스트 인증 외 지원 범위, 계정 간 저장 동기화는 미정.

- 게스트 인증에 서버 발급 난수 토큰을 사용하는 방식은 제안. 브라우저·기기 정보 기반 자동 식별은 안정적인 인증 수단으로 간주하지 않는다.
