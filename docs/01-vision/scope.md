# MVP 범위

- 상태: 초안
- 담당: 기획자 + AI
- 관련 문서: [콘셉트](concept.md), [제작 단계](../08-production/milestones.md)

## 첫 MVP 범위 — D117

현재 구현 목표는 전체 흐름을 한 번 완주하며 준비한 장비로 꾸미는 재미와 적재 퍼즐의 재미를 검증하는 것이다. 아래에서 이후 범위로 둔 결정은 폐기하지 않고 장기 기획으로 보존한다. 이 구분이 아래 상세 기획보다 첫 구현 우선순위에 앞선다.

| 첫 MVP | 이후 확장 |
|---|---|
| 첫 시작 시 캐릭터 선택(D123) | 캐릭터 수 확대·상세 커스터마이징 |
| 단순한 돈 벌기·장비/식재료 구매 | 업무 유형·알바의 상세·정교한 급여 계산 |
| Papers, Please 참고의 전체 화면 서류 검토 업무 1종(D153) | 다른 업무 미니게임·성과급·규정 확장·스토리 판단 |
| 소수 장소·자리 선택 | 신규 장소와 자리 유형 확대 |
| 최소 장비의 왕복 격자 적재·회전·제한 시간·귀가 착불 택배 | 차량 교체·정교한 난도 조절·대규모 아이템 |
| 매주 현장 배치·철거: 마름모 격자, 지면·테이블 자동 배치, 확정/취소 후 캐릭터 이동·설치(D167) | 대규모 장소 콘텐츠 |
| 날짜별 날씨·일기예보 확인·옷 교체·날씨 부적합 시 STA 추가 감소(D121~D122) | 대규모 의상 수집·정교한 날씨 시스템 |
| 음식 하나의 조리·섭취·휴식, 풍경 감상 중 이동·의자 착석(D165~D166) | 여러 요리·숙련·만족도 효과·아침 메뉴 상세 |
| 기본 저장·정산·다음 캠핑 | 배고픔·졸음·체력의 복합 페널티 |

MVP에서 옷을 갈아입을 수 있고, 날씨에 맞지 않는 옷을 챙겨가면 체력(STA)이 더 빨리 감소한다(D121). 의상 종류·수량·부위, 날씨 종류·전환 여부, 적합성 판정·추가 소모량, 출발/현장 의상 변경 시점과 운반 크기는 미정이다. 첫 검증은 최소 의상·날씨 적합성 범위로 제한하며 대규모 의상 수집·날씨 시뮬레이션을 전제하지 않는다.

날짜마다 날씨가 다르며 일기예보로 미리 확인할 수 있다(D122). 예보 확인 → 날씨에 맞는 옷 준비/착용 → 부적합 시 STA 추가 감소를 MVP에서 연결한다. 날씨 종류·예보 가능 기간·정확도/변경 여부·하루 중 날씨 전환·날씨 확정 시점·예보 진입 화면은 미정이다.

첫 시작 시 캐릭터를 고를 수 있도록 첫 MVP에 포함한다(D123). 기존 인증·진행 조회 후 신규 플레이는 캐릭터 선택 → 첫 주 시작으로 연결하고 기존 진행은 저장된 캐릭터·단계로 이어간다. 첫 MVP 후보는 남성 1명·여성 1명이다(D128). 구체 외형·성능 차이·나중에 변경 가능 여부·상세 커스터마이징은 미정이며 현재 그림은 프로토타입이다. 의상 교체(D121)와 기본 캐릭터 선택을 구분한다.

장소/아이템 수·음식 선택·제한 시간 수치는 테스트용 제안으로 별도 정한다. 기존 로그인·저장 구현은 재사용을 검토하며 이번 단계에서 재구현을 전제하지 않는다. UX는 저장소의 전체 흐름·화면 명세와 [디자인 시스템](../../design/mvp/design-system.md)을 연결하고 Godot에서 작은 단위로 구현·검증한다(D125). 필요한 와이어프레임과 시각 어셋은 해당 단위에서 만들며 Figma는 선택 도구다. 폰·폴드·웹 대응 요구는 유지한다.

첫 주에 낡은 텐트·기본 버너·접이식 의자를 무료로 받는다. 라면은 한 끼 5원이다. 기본 캠핑복은 입고 출발하며 방수 겉옷은 트렁크 한 칸에 싣는다. 두 날의 날씨가 다르면 실어 온 겉옷을 현장에서 바꿔 입을 수 있다. 압축팩은 이후 확장이다.

## 목표

돈을 벌어 아이템을 구매하고 크고 화려한 캠핑장을 꾸미는 핵심 경험(D066)을 Android 기기에서 검증한다. 첫 검증의 아이템 수·공간 크기·완료 조건은 별도로 정한다.

## 첫 진입 방향

첫 방문에는 로그인 전에 캐릭터를 가볍게 움직여보는 캠핑 인트로로 분위기를 경험한 뒤 인증·첫 주를 시작한다(D045~D047). `시작하기`는 인트로 진입부터 사용할 수 있고 이동량·시간 조건 없이 접속한다(D050). 로그인 상태가 유효하면 이어하기, 인증이 필요하면 로그인·가입, 신규 진행이면 첫 주 시작으로 분기한다(D051). 전용 체험의 길이·구체 조작·전환은 [유저 플로우 초안](../05-ux/user-flow.md)에서 구체화한다. 인증 후 신규 진행은 캐릭터 선택을 거쳐 첫 주 월요일 업무로 진입한다(D123, D053 일부 대체). 별도 로비 없이 업무 안에서 짧게 조작을 안내한다. 기존 진행은 저장된 단계로 이어간다. 반복되는 한 주의 월~금 업무와 토·일 캠핑 순서는 유지한다.

## 캠핑장 선택과 평일 마감

서류 업무는 20초에 마감하며 제출한 정답·오답에 따라 급여를 받는다(D159). 캠핑은 금요일에 장소를 선택하고 즉시 이용료를 지불한다(D169). 선예약과 취소 위약금, 예약 만석은 제외한다.

## 현재 캠핑 반복 — D090~D091

매주 캠핑 장소를 선택할 수 있고, 주말마다 가져간 장비를 다시 펼쳐 캠프를 꾸민다(D090). 귀가 전에는 장비를 철거하고 트렁크의 격자 적재 퍼즐을 다시 한다(D091). 귀가 적재에 실패한 장비는 집 택배함으로 보낸다. 차에 이미 남아 있는 미배치 물건과 철거한 물건을 어떻게 함께 적재 판정할지는 미정이다.

출발 적재에 못 실은 물건은 집에 남아 다음 주에 가져갈 수 있다(D076·D084). 귀가 적재에 못 실은 장비는 택배함에서 개당 5원을 내고 받는다(D168).

이 결정은 배치를 매주 유지하던 D067, 새 구매품만 운반하던 D073의 범위, 철거·귀가 적재가 없던 D079 및 D089의 해당 전제를 대체한다. 원하는 물건만 배치하는 D088, 격자 배치·트렁크 회전, 차량 교체 성장은 유지한다. 매주 사용할 기존 보유 장비도 출발 짐 싸기 대상이다.

장소를 고를 때 게임 내 이용료를 내고 이번 방문에 사용할 캠핑 자리 크기를 선택한다(D104). 더 넓은 자리를 선택할 수 있으며 영구 토지 확장이나 현장 공간 확장 구매는 제공하지 않는다. 장비·차량 성장은 유지한다. 장소별 크기 선택 범위·칸 수·이용료·결제 시점·변경/취소/환불은 미정이다. 장소는 금요일에 바로 선택한다(D169). 모든 캠핑 장소는 처음부터 선택할 수 있으며 장소별 이용료에 차이를 둔다(D106). 진행도·레벨 등 별도 장소 해금 조건은 두지 않는다. 실제 방문에는 이용료 지불이 필요하며 장소별 가격·잔액 부족 처리·자리 크기에 따른 가격 산정은 미정이다. 콘텐츠 수·철거 조작은 미정이다. 귀가 적재에도 시간 제한을 둔다(D092). 시간 종료 시 정상 적재한 물건만 가져오고 나머지 장비는 착불로 보낸다. 귀가 적재는 한 번만 진행하며 재도전 없이 시간 종료 시 결과를 확정한다(D094). 구체 제한 시간·자동 귀가 여부는 미정이며 출발의 자동 전환 규칙을 귀가에 자동 적용하지 않는다.

캠핑 장소마다 풍경과 배치 가능한 공간의 모양을 다르게 구성한다(D105). D104의 자리 크기 선택과 구분하며, 구체 장소 종류·개수·공간 형태·칸 수는 미정이다. 장소별 보너스·위험·날씨 효과는 이번 결정으로 추가하지 않는다.

## 평일 선택 활동

당일 업무 후 알바는 하루 최대 1회 선택한다(D056). 기본급만으로 기본 캠핑이 가능하다. 금요일 아이템 쇼핑 → 메뉴·식재료 구매 → 출발 적재 순서이며 아이템 구매 없이 진행할 수 있다(D086). 구체 수입·지출은 미정이다.

## 요리 범위

첫 버전의 저녁 요리는 라면과 꼬치구이 두 계열로 시작한다. 라면은 조리 장비에 따라 만들 수 있는 레시피가 늘어나고, 꼬치구이는 직접 고른 재료를 꼬치에 꽂아 굽는다. [요리 규칙](../03-systems/README.md#요리)을 참고한다.

일요일 아침은 커피와 토스트로 구성한다. 첫 테스트에는 믹스커피와 버터 토스트를 제안한다. 드립커피·원두 선택과 그릴·오픈 토스트의 도입 시점은 미정이며, 차는 이후 확장 후보로 둔다.

## 음식 소모와 생활 상태

먹고 소모한 음식·사용 재료는 귀가 짐에서 제외하고 남은 재료·음식은 운반할 때 트렁크 공간을 차지한다(D095). 배고픔·졸음 요소를 채택했다(D096). 배고픔 방치 시 활동에 불이익을 준다(D097). 배고플수록 설치·철거 같은 활동의 STA 소모가 늘고(D098), 복잡한 음식 섭취의 만족도를 높인다(D099). 구체 수치·만족도 효과와 MVP 검증 범위는 후속 정의한다.

체력(STA)이 0이 되면 토요일에는 취침해야 하고 일요일에는 귀가해야 한다(D100). 체력이 남아 있을 때의 사용자 취침·활동 선택은 유지한다. 일요일 STA 0이면 자유 활동은 종료하지만 철거·귀가 적재는 수행한다(D101). 0 도달 시 진행 행동의 정리·전환 시점, 취침 회복량, 철거·적재 중 체력 처리의 세부는 미정이다. 졸음 수치와 STA 0은 같은 조건으로 취급하지 않는다.

## 후속 확장 — 강아지 동반 캠핑

강아지를 데리고 캠핑을 떠날 수 있도록 한다. 출발 전에 강아지용 짐과 사료도 챙긴다. 필요한 짐 종류, 적재 공간, 사료 수량과 현장 상호작용은 미정이다.

## 미정

나머지 필수·제외 기능, 계열별 레시피 수, 플레이 시간, 목표 기기, 구체적 완료 조건은 아직 정하지 않았다.
첫 플레이 순서와 시간 배분은 [15분 세션 흐름](../02-gameplay/session-flow.md)을 참고한다.
성장·꾸미기·매주 장소 선택·설치/철거·왕복 적재는 채택했다. MVP의 장소 수·장비 수·귀가 퍼즐 난도·손실 표시·자리 크기·이용료는 미정이다. 귀가 미적재 장비는 택배함에서 개당 5원에 받을 수 있다(D168). 날씨와 의상 적합성의 체력 효과는 D121로 채택했다. 상세 날씨 전환·별도 수집 시스템·멀티플레이는 확정하지 않았다.

## 초기 난도와 재미 검증 — D102

초기 테스트는 적재 제한 시간·트렁크 여유 공간·체력 여유를 넉넉하게 설정한다. 체력 소진과 물건 택배 수령 비용은 사전에 명확히 알리고, 꾸미기·풍경 감상을 즐길 시간이 충분한지 확인한다. 졸음의 추가 페널티는 기존 체력과 역할이 겹치는지 검토할 때까지 보류한다.

왕복 적재 제한 시간·귀가 재도전 없음·미적재 장비 착불 처리·체력 0의 요일별 종료는 유지한다. 구체 시간·칸 수·소모량·경고 기준은 플레이 테스트로 조정하며, 풍경 감상·배치 검토 중 자원 소모/정지 정책은 미정이다.

관찰할 항목은 적재 성공·택배 이용 빈도, 실패 이유를 이해하는지, 반복하며 개선하는지, 꾸미기와 감상에 쓸 여유, 다음 캠핑을 하고 싶은지다. 수치 목표나 검증 통과를 아직 선언하지 않는다.

## 결정 방식

핵심 경험과 첫 플레이 흐름을 정한 뒤 기능을 `MVP 필수 / 이후 후보 / 제외`로 분류한다.
필수 기능에는 관찰 가능한 완료 조건과 필요한 에셋을 연결한다.

현재 첫 완주 웹 MVP 구현과 임시 데이터·후속 범위는 [구현 기준](../07-technical/mvp-v1.md)을 따른다. 현장의 3D 좌표는 표현 전체를 입체 모델로 바꾼다는 뜻이 아니며 배경·캐릭터·장비 에셋은 2D다(D134~D136).
