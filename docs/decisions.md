## 추천안·미정

- Godot 4 안정 버전 + GDScript는 추천안. 버전·언어 확정 전.
- Figma는 UI·흐름·아트 설계 도구로 논의. 링크와 필수 범위 미정.
- 2D/3D, 시점, 화면 방향, 핵심 재미, MVP, 온라인 여부, 수익 모델 미정.
- 텐트·모닥불·요리·날씨·성장 등은 예시·후보.
- 두 번째 참여자의 역할, 일정 미정.

- 웹 배포 주소·브라우저 지원 범위, 기기 간 저장 시점·동시 접속·충돌 규칙은 미정. 웹 제공 방향은 D017로 확정.

- ID·비밀번호 입력 규칙과 복구 코드 세부 정책은 미정. 복구 코드 도입은 D015로 확정. 자동 세션 유지와 사용자가 입력하는 인증 정보를 구분한다. 브라우저·기기 정보만으로 인증하지 않는다.
- Google 연결 대상에 이미 진행 데이터가 있는 경우의 처리와 연결 후 복구 코드의 유효 범위는 미정.
- 사용자가 ID·비밀번호 로그인을 끄는 기능은 추후 후보로 두며 현재 구현 범위에 포함하지 않는다.

- 서버 추천안: 단일 서버의 Caddy + Python/Django·REST Framework + PostgreSQL, Docker Compose 관리. 기술 선택은 사용자 검토 전이며 확정하지 않았다. [상세](07-technical/server-architecture.md)
