# AWS 운영 환경 설계

- 상태: 운영 대상 확정, 상세 실행 설정은 초안
- 담당: AI, 기획자 검토
- 관련 문서: [서버 아키텍처](server-architecture.md), [결정 기록](../decisions.md)

## 확정

운영 서버는 AWS Lightsail Linux의 공인 IPv4 포함 월 $7 요금제(메모리 1GB, SSD 40GB)를 기준으로 설계한다.
가격은 선택 시점의 기본 요금이며 세금·백업·초과 트래픽·도메인 등의 총비용을 보장하지 않는다. 생성 전 해당 리전의 최신 요금과 포함량을 확인한다.
DB는애플리케이션 서버와 분리한 AWS DB 서비스에 둔다. RDS for PostgreSQL을 추천하며 제품·사양·예산은 검토 전이다.
현재는 설계만 수행하며 AWS 리소스 생성·결제·배포는 수행하지 않는다.

## 배치 제안

Lightsail에는 Caddy와 Django API만 Docker Compose로 배치한다. 운영 PostgreSQL은 같은 서버의 컨테이너에 두지 않는다.
별도 관리형 DB 후보는 Amazon RDS for PostgreSQL이다. 로컬 개발·CI에는 별도 테스트 PostgreSQL 컨테이너를 사용할 수 있다.
서버 소프트웨어 구성은 기존 추천안이며 구체적 버전과 설정은 구현 단계에서 검증한다.
AWS 전용 API 의존을 최소화해 다른 Linux VPS로 이전하기 쉽게 한다.

- 정적 웹 파일과 /api/v1/를 같은 HTTPS 호스트에서 제공한다. Android도 같은 API를 사용한다.
- Lightsail 방화벽에는 웹용 80·443만 공개하고 SSH는 관리 IP 등으로 제한한다. DB는 비공개 네트워크로 연결하고 API 서버에서만 접근할 수 있게 한다.
- 고정 IP를 인스턴스에 연결하고 HTTPS와 Google 로그인에 사용할 호스트 이름을 정한다. 도메인 구매·DNS 유료 서비스는 별도 결정한다.
- 지원되는 Linux와 보안 업데이트 정책을 선택한다. 비밀 설정은 서버에서 주입하고 저장소에 넣지 않는다.

## 별도 DB 연결 제안

RDS를 선택하면 Lightsail과 같은 AWS 리전의 기본 VPC에 배치하고 Lightsail VPC 피어링으로 연결하는 구성을 우선 검토한다.
RDS는 public access를 끄고 DB 보안 그룹·라우팅·DNS를 구성하여 필요한 Lightsail API 접근만 허용한다. DB 연결 TLS와 인증서 검증을 적용한다.
Lightsail의 직접 피어링은 기본 VPC를 사용하므로 계정의 기본 VPC 유무와 DB 서브넷 구성을 먼저 확인한다. 임의의 커스텀 VPC에 바로 연결된다고 가정하지 않는다.
비용을 낮추려면 Single-AZ의 작은 지원 인스턴스를 우선 견적하되 자동 장애 전환은 제공하지 않는다는 점을 반영한다. Multi-AZ는 별도 비용·가용성 선택이다.

## 1GB 메모리 제약

- Godot 내보내기·이미지 빌드·테스트는 CI나 개발 컴퓨터에서 수행하고 서버에는 산출물만 배포한다.
- API 워커는 1개부터 시작하고 요청·스레드 동시성을 제한한다. API의 DB 연결 수를 보수적으로 제한한다.
- API, Caddy, OS 전체의 상주 메모리와 순간 피크를 측정하여 조정한다. 서비스별 메모리 제한은 측정 후 정하며 현재 성능을 보장하지 않는다.
- 비밀번호 해시 메모리·연산 비용을 줄여 보안을 약화시키기보다 인증 동시 요청을 제한하고 필요한 경우 서버를 증설한다.
- 로그 회전, 릴리스 보존 개수, Docker 이미지 정리를 구성한다. 선택적 swap은 일시적 피크 대응용이며 RAM 대체로 간주하지 않는다.
- 초기에는 Redis, 작업 큐, 로드밸런서, NAT Gateway를 추가하지 않는다.

## 배포·검증

버전 고정 이미지와 Godot Web 산출물을 준비하고 배포 → DB 마이그레이션 → 상태·로그인·웹 로딩 확인 순서로 진행한다.
1GB 환경에서는 무중단 배포를 전제하지 않는다. 이전 릴리스로 복귀하는 절차와 비가역 DB 변경 시 복구 방법을 마련한다.
실제 사용 패턴과 인증·저장·백업·배포 피크를 재현하고 메모리 부족, 지연, DB 연결, CPU 버스트 상태를 확인한다.
반복적인 메모리 부족이나 목표 성능 미달 시 2GB 이상 요금제로 변경한다. 사용자 수의 고정 한도는 측정 전 약속하지 않는다.

## 백업·비용

총비용은 Lightsail $7 + 별도 DB 인스턴스·스토리지·백업 초과·전송 등의 비용이다. 이전 $7 선택은 API 서버의 기본 요금이며 전체 서비스 비용이 아니다. 별도 DB 비용은 호스팅 예산에 포함해 검토한다.
RDS 선택 시 자동 백업·보존 기간·복구 시점·삭제 보호를 설정하고 실제 복원 검증을 포함한다. 암호화된 백업을 NAS 등 별도 장비로 수신하는 방식은 후보이며 접근 경로·자동화·주기·보존 기간은 미정이다.
NAS의 DB 포트를 공개하거나 같은 서버에만 백업하는 방식은 사용하지 않는다.
유료 스냅샷·S3·관측 서비스는 요금과 필요성을 검토한 뒤 도입한다. 기본 호스팅 요금만으로 백업까지 포함된다고 간주하지 않는다.
트래픽·디스크·지출을 점검하고 예산 알림을 검토한다. 예산 알림은 과금을 자동 차단하는 상한이 아니다.

리전, 주소·DNS·인증서 구성, 백업 대상, 서버 도구 버전과 실제 메모리 설정은 미정이다.
