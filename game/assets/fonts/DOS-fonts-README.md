# 도스필기 — 손글씨 도트 UI 시안

- 제작: 이담허(leedheo / Damheo Lee)
- 원본: https://github.com/hurss/fonts
- 버전 기준: 3fc1181c6b4af095206068188c3ea966d6738add
- 원본 경로: ttf/DOSPilgi.ttf (수정하지 않은 원본)
- 라이선스: 함께 보관한 DOS-fonts-LICENSE.txt (MIT)
- 출처 표시: 글꼴(폰트)로 도스필기체(leedheo 제작)를 사용하였습니다.

Godot 독립 디자인 시스템 전시 씬에 시안으로 적용한다. 16px·32px 정수 배율, 안티앨리어싱·서브픽셀 비활성으로 픽셀 획을 보존한다. 미지원 문자는 기존 Noto Sans KR로 폴백한다. 전체 한글·기호 범위와 Android 실기기 가독성은 별도 검증하며, 실제 플레이 UI 폰트는 아직 교체하지 않았다.
