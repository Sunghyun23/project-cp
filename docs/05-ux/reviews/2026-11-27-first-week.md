# SC-FIRST-WEEK 검토

- 일자: 2026-11-27
- 대상: 첫 주 업무 UI와 공통 UI 입력 변경, 커밋 전 작업 트리
- 환경: macOS · Godot 4.7.2 Compatibility · 기존 로컬 Java/PostgreSQL API

## 확인

`tools/verify-character-select.gd`를 확장해 실제 로컬 API와 별도 임시 세션으로 실행했다. 기존 로컬 저장 경로와 진행을 덮어쓰지 않는다.

1. 캐릭터 선택의 클릭·키보드·패드 입력 이벤트, 통신 실패/조회 복구, 선택 저장·재접속 유지 통과.
2. 재접속 후 월요일 업무 화면으로 진입 통과.
3. 업무 통신 실패 시 버튼 비활성·재조회 요구, 조회 뒤 같은 날짜 유지 통과.
4. 월~금 5회 업무 저장, 평일 자동 연결·수입/체력 실제 변화·캐릭터 유지 통과.
5. 금요일 결과 후 쇼핑 단계 전환·업무 화면 제거 통과.

단순 업무 프로토타입의 검증 값은 5회 수입 합계 +50, 체력 -30이다. 이 값은 최종 밸런스 확정이 아니다. 업무 결과는 서버 응답 전후 차이로 표시한다. API/DB 스키마 변경은 하지 않았으며 서버 14개 통과 기록은 직전 캐릭터 선택 변경의 결과다.

PC 1280×900·폰 크기 390×844·펼친 폴드 크기 820×920 실제 렌더링을 확인했다. 폰 안내를 더 짧게 다듬고 폰 캡처를 갱신했다. PC·폴드 캡처는 그 문구 수정 직전이므로 배치는 같고 안내 문구만 다르다.

## 미실행

물리 키보드·패드·Android 터치, Android 실기기·접기/펼치기·안전 영역·웹 브라우저 실제 로그인부터 플레이는 미검증이다. 자동 입력 이벤트 검사를 장치 검증으로 표시하지 않는다. 공개 서버 배포와 Git 푸시는 수행하지 않는다. 웹 빌드는 별도 실행 결과로 기록한다.
