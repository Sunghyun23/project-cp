Figma는 UI·화면 흐름·스타일 가이드에 활용할 수 있다. 에셋 제작 도구는 스타일에 맞춰 결정한다.
사용자 요청으로 AI가 [2D 픽셀 캠핑장 프로토타입](pixel-prototype.md)의 낮·밤 배경과 귀여운 캐릭터를 직접 생성하고 움직임을 구현했다. 최종 화풍·전체 에셋 제작 범위는 미정이다.
